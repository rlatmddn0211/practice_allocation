# 후보 검증 이후의 연구 순서

2026-10-19. [38번 후보 안내](../38_candidate_factor_publication_v1/candidate_guide_ko.md)와 [37번 완료 결과](../37_f08_integrated_candidate_review_v1/report_ko.md)에 근거한 후속 설계 제안이다. **실험 구현·학습·평가·예약은 실행하지 않았다.** 원래 파일럿 설계와 완료 버전은 보존한다.

추천 순서는 **제한된 재현 → 상태에 따라 선택할 가치가 있는지 확인 → 이른 신호의 예측 실패를 직접 측정 → 비용 포함 실제 배분 → 적용 범위 확장**이다. 우선 제안하는 패킷은 B 구성, 새 원래 seed 4개, 후속 seed 2개, 비교 조건 4개의 32분기다. 사전학습 포함 2.08M 학습 step이며, 연구용 초기·최종 평가까지 포함한 본 패킷의 환경 실행 상한은 9.28M step이다.

- [기계 판독용 제안 설정](proposal.json)
- [예산 산식·출처 확인 코드](check_plan.py)

이 규모는 후속 투자를 판단하기 위한 작은 재현 패킷이다. 원래 seed 네 개로 충분한 검정력이나 범용 효과가 확보된다고 주장하지 않는다. 동일한 고정 배분이 일관되게 강하면 그 결과를 기준선으로 채택하고, 적응형 선택의 가치와 구분한다.
