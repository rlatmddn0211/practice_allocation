# 공유 정책에서 짧은 진단의 예측 오류와 추가 연습 배분

**연구로 진행할 근거는 있다. 현재 가장 설득력 있는 출발점은 중간 학습 성과가 최종 배분 선택을 틀리게 만드는 사례가 있다는 것이다. 그러나 저비용 보정법의 성공은 아직 확보하지 못했다.** 특정 과제의 전이 효과를 주장하기보다, 예측이 실패하는 조건과 보정의 비용 회수 가능성을 검증하는 방향이 적절하다.

현재 E0–E2는 탐색 자료로 고정한다. 아래 가설과 방법을 확인한 뒤 만든 새로운 독립 자료에서 검증해야 한다. 기존 파일럿과 E0–E3 실행 규약은 유지하며, 아래 후속 학습 규모는 설계 제안이다.

## 연구에서 답할 질문

> 공유 정책의 추가 강화학습에서, 초기의 과제별 학습·전이 신호가 남은 예산 뒤의 전체 성능을 잘못 예측하는 조건을 식별할 수 있는가? 그 조건을 이용해 필요한 진단만 수행하면, 진단 비용을 포함한 동일 총예산에서 기존 배분법보다 높은 성능을 얻는가?

기여 후보는 두 개로 제한한다.

1. **예측의 적용 범위:** 어떤 측정 가능한 학습 상태와 잔여 길이에서 값싼 신호가 배분의 순위·이득 부호를 보존하거나 실패하는지 밝힌다.
2. **의사결정의 개선:** 그 조건을 이용한 보정과 진단 중단이 실제 비용을 회수하는지 검증한다. 예측 오차만 낮아지는 것으로 충분하지 않다.

Aioli는 이미 짧은 학습 반응으로 과제 간 반응 행렬을 갱신하고 혼합비를 조정한다. 또한 반복 평가의 추가 비용을 인정한다. 그러므로 짧은 진단, 동적인 전이 행렬, 전체 성능 최적화만으로 차별화를 주장할 수 없다. [Aioli, §5와 §8](https://arxiv.org/html/2411.05735v2)

TAC는 RL 학습 중 얻는 advantage와 gradient 정보를 재사용하여 전이를 고려한다. 우리 방법이 추가 rollout을 요구한다면 이런 값싼 대안과 비교해야 한다. SAC에 맞춰 바꾼 방법은 원 논문의 재현이 아니라 적응판으로 명시한다. [TAC, §3와 Appendix C.2, 2026 프리프린트](https://arxiv.org/html/2606.25178v2)

다른 직접 선행연구와의 경계는 [18번 문헌 비교](../18_practice_allocation_literature_review_v1/literature_review_ko.md)에 있다. 공유 SAC의 replay 지연과 rollout 측정 비용이 실제 오류를 설명하고, 그 설명이 새로운 상태에서 좋은 선택을 만들 때 좁은 방법 기여를 주장할 수 있다. 현상들을 함께 언급하는 것만으로 새로운 알고리즘이 되지는 않는다.

이 비교에는 중요한 제한이 있다. 선택과 결과가 같은 평가 사례 bank를 사용하므로 새로운 사례에 대한 검증이 아니며, 원래 상태도 같고 continuation만 분리했다. 후보별 학습·평가 비용도 아직 차감하지 않았다. 20k는 목표 40k의 절반이고, 다섯 후보를 한 번씩 20k 학습하면 100k가 필요하다. 위 두 반복 선택은 200k를 사용한다. 따라서 **20k 자료에서 순위가 바뀐 사실을 곧바로 매우 짧은 gradient 진단의 실패나 저비용 알고리즘의 성능으로 확대하면 안 된다.**

E0의 같은 출발점 재현에서는 DC 집중의 이득이 관측되었지만, 독립 원래 seed를 사용한 E1의 DC 집중 이득은 +0.39%p에 그쳤다. E2의 DO 성능에서 DC 증가와 WO 증가를 비교한 차이는 −0.78%p였다. 이 결과들은 보편적인 DC donor 가설보다, 출발 상태와 목적에 따른 배분 가치의 변화에 초점을 맞추도록 한다. [E0–E2 상세 보고서](../17_e0_e2_detailed_research_report_v1/README.md)

## 가장 중요한 제약은 진단 비용

현재 E1 출발점에서 공개 진단 한 번은 과제당 100개, 총 400개 에피소드였다. 6개 출발점의 실제 비용은 **65,294–115,666 환경 step, 평균 90,207 step**이다. 40k 추가 학습 예산의 1.63–2.89배다. 현재 평가를 매번 다시 수행하면서 저비용 배분을 주장하는 것은 성립하지 않는다. [실제 비용](results/20261013T104734Z_54c5eae6/public_diagnostic_costs.csv)

사전학습 때 이미 얻은 공개 진단과 로그를 모든 방법이 동일하게 재사용하는 경우에는 해당 비용을 공통 준비 비용으로 분리할 수 있다. 그러나 의사결정을 위해 새로 얻는 정책 평가와 probe 학습은 반드시 청구해야 한다. 과거 공개 진단이 있다는 이유로 새로운 probe 정책의 성공률을 무료로 알 수 있는 것은 아니다.

예를 들어 총예산 B=40k라면 진단 상한 10%는 4k, 20%는 8k다. 현재의 정확한 focus 혼합비 한 주기는 500-step 에피소드 8개, 즉 4k다. 다섯 배분을 모두 한 주기 시험하는 데만 20k가 든다. 10% 예산으로 다섯 후보를 전부 측정하는 설계는 불가능하다. 가능한 첫 후보는 학습 중 이미 생성된 정보를 쓰는 방법, 소수 후보만 진단하는 방법, 또는 진단을 하지 않는 방법이다.

평가를 줄이면 정확도 문제도 생긴다. 4개 과제에서 한 사례씩 끝까지 평가하면 최악 2k step이지만, 이 네 사례로 작은 성공률 차이를 안정적으로 구분하기는 어렵다. 이 사실은 저비용 진단이 반드시 성공할 것이라고 가정하지 말아야 하는 이유다. 예산이 부족하면 무리하게 순위를 정하는 대신 기본 배분을 유지하는 행동까지 평가해야 한다.

## 예측할 대상과 비용 정의

전체 성공률을 \(J(S)=\frac14\sum_j p_j(S)\)로 고정한다. \(S\)는 actor·critic, optimizer, entropy, replay, 수집기와 난수 상태를 포함한 학습 상태다. 고정 배분 \(a\)와 길이 \(H\)에 대해

\[
\Delta(a,H\mid S)=\mathbb E[J(U_a^H(S))-J(S)],\qquad
D(a,H\mid S)=\Delta(a,H\mid S)-\Delta(U,H\mid S).
\]

예측 정확도는 Δ와 과제별 변화로, 배분 선택은 D의 순위·부호와 실제 선택 손실로 평가한다. 손실을 본 과제도 합산하며 평균 성능과 최악 과제 유지 지표를 구분한다. 평균 개선을 유지 성능의 보장으로 표현하지 않는다.

온라인 비교의 주 제약은

\[
C_{\rm learning\ interactions}+C_{\rm diagnostic\ interactions}\le B_{\rm env}
\]

다. gradient 계산, checkpoint 복제와 복원, 평가 추론은 wall time과 GPU time으로 별도 기록한다. 환경 step과 초를 임의로 더하지 않는다. 데이터 수집 예산 기준의 주 결과와 계산 시간까지 맞춘 보조 결과를 함께 보고한다.

분기 진단의 회계도 명확히 한다. m개 후보를 r씩 시험하고 그중 하나의 상태를 유지하여 계속 학습한다면, 선택된 모델의 실제 학습 길이는 평가 비용이 c일 때 \(B-(m-1)r-c\)다. 선택된 r은 한 번만 세고, 버린 분기의 r도 지불한다. 순서대로 진단한 경우에는 바뀐 replay·optimizer 상태를 그대로 포함한 실제 학습을 평가한다. 다른 고정 분기들의 점을 이어서 전환 전략의 결과로 만들 수 없다.

예측기 훈련용 분기와 튜닝 비용은 오프라인 준비 비용으로 따로 공개한다. 최종 블라인드 평가는 selector에 노출하지 않고 모든 방법에 공통으로 시행하되, 연구 전체의 실제 환경·계산 비용에는 포함한다.

## 실패 조건에 대한 반증 가능한 가설

| 후보 조건 | 예측 | 구별할 실험과 반증 기준 |
| --- | --- | --- |
| 수집 비율과 replay 학습 노출 사이의 지연 | probe 길이 r이 replay 크기 R에 비해 작고 최종 H는 더 길면, 현재 반응이 최종 반응을 덜 잘 예측할 수 있음 | 실제 replay batch의 과제·데이터 나이를 기록. 같은 저장 자료와 update 수에서 old/new sampling 비중을 통제했을 때 예측 오류가 줄지 않으면 지연 설명을 약화 |
| 학습 지표와 성공률의 불일치 | dense return·actor/critic 신호의 순위가 최종 binary 성공률 순위와 다를 수 있음 | 같은 정책 snapshot에서 여러 신호의 out-of-state 예측을 비교. 단순 성공률/return 보정으로 충분하면 복잡한 전이 모델의 필요성이 낮음 |
| 과제별 이득과 손실의 시간 변화 | 초기의 도움·망각이 서로 다른 속도로 나타나면 단일한 고정 전이 행렬이 오판할 수 있음 | self 항만, 전체 과제 항, horizon 조건화를 분리한 제거 실험. 전체 과제·horizon 항이 새 상태에서 선택을 개선하지 못하면 해당 가설을 지지하지 않음 |
| 관측 잡음에 비해 작은 배분 차이 | 불확실한 순위에 추가 진단을 쓰면 비용만 잃거나 우연한 승자를 고를 수 있음 | 평가 사례·continuation·original seed 변동을 구분. 잡음 보정 후 시간별 순위 변화가 사라지면 horizon 설명을 약화. zero-probe와 진단 중단 정책 비교 |

첫 가설은 현재 구현에서 특히 측정하기 쉽다. 가득 찬 크기 R=100k의 FIFO replay에서 추가 수집량 h≤R이고 uniform sampling을 한다는 단순 회계 아래, 새 데이터 비중은 마지막 시점에 h/R, 구간 평균은 약 h/(2R)다. 따라서 20k와 40k는 각각 최종 20%·40%, 평균 약 10%·20%의 새 데이터 노출에 해당한다. 이는 데이터 나이의 회계이며 성능에 대한 인과적 증명이 아니다. 실제 batch에서 확인하고, 오래된 데이터의 유익함과 단순 과제 비중을 분리해야 한다.

또한 20k 결과가 같은 20k의 다른 continuation을 예측하는 능력 자체도 불안정했다. 기존 분석의 그 선택 결과는 Uniform 대비 −3.60%p였다. 그러므로 모든 오류를 horizon 차이 탓으로 돌릴 수 없다. [기존 규칙 비교](../17_e0_e2_detailed_research_report_v1/results/20261013T052346Z_7e2f6a68/rules.csv)

## 최소 방법 후보

처음부터 큰 예측 모델을 만들기보다 **기존 국소 점수에 상태와 horizon을 조건으로 한 작은 잔차 보정**을 붙이는 편이 검증하기 쉽다. 다만 이번 분석에서 확인했듯이 다른 seed의 평균 drift를 더하는 것만으로는 충분하지 않았다.

입력 후보는 현재 과제별 성능과 최근 return 변화, actor/critic별 gradient 관계, 수집 비율과 replay batch 비율의 차이, 데이터 나이, 남은 H/R, 신호의 변동성이다. 학습 중 training 성공률은 탐험 정책·방문 상태에 의존하므로 deterministic 평가 성공률과 동일한 양으로 취급하지 않는다. SAC critic loss의 감소를 곧바로 policy 성공률 개선으로 읽지도 않는다.

첫 모델은 과제별 변화와 그 합을 예측하고 negative transfer를 허용한다. task 이름을 외우는 대신 측정 특징을 사용한다. 복잡한 모델이나 permutation-invariant 모델로 확장하기 전에 단순 회귀와 horizon 입력만 추가한 모델을 반드시 비교한다. 현재 6개 상태로 이 모델을 학습해 검증됐다고 주장할 수는 없다.

진단 정책은 다음 순서로 제한한다.

1. 이미 있는 로그로 후보와 불확실성을 계산한다. 높은 확률로 기본 배분을 이기지 못하면 추가 진단을 하지 않는다.
2. 후보 순위를 바꿀 수 있는 제한된 진단만 선택한다. rollout 없는 gradient 계산, 소량의 공개 사례 평가, 또는 소수 후보의 학습 probe를 구별한다.
3. 진단을 통해 얻을 선택 개선과 잃는 학습 기회를 같은 최종 성공률 단위로 예측하여 비교한다. 불확실성 감소 자체만 최대화하지 않는다.
4. 실제 비용과 바뀐 학습 상태를 기록하고 남은 예산으로 학습한다. 예산이 작거나 증거가 약하면 기본 배분으로 돌아간다.

기본 배분은 무조건 Uniform로 고정할 필요가 없다. 개발 자료에서 정한 고정 배분도 같은 정보·비용 조건에서 경쟁시킨다. 진단 규칙과 중단 임계값은 최종 원래 seed·과제 조합을 보기 전에 동결한다. 이 절차는 구현 후보이며 최적성이나 성능 향상을 보장하지 않는다.

## 단계별로 비용을 제한하는 검증안

**단계 0: 기존 자료 재분석 — 완료.** 이번 실행은 학습 0 step·환경 평가 0회다. 순위 반전, continuation 분리 선택, 단순 보정의 실패, 공개 진단 비용을 계산했다. E0–E2 자료를 새 가설의 확증 자료로 재사용하지 않는다.

**단계 1: 짧은 신호가 실제로 있는지 확인하는 개발용 실험 — 제안.** 기존 E1의 6개 전체 checkpoint에서 5개 배분 × 새 continuation 3개 × 4k를 수행한다. 총 **90개 probe·360k 학습 step**, 추가 사전학습은 없다. 0과 4k에서 gradient·replay 노출·return을 기록하고, 기존 20k·40k 결과를 기대 반응의 탐색용 label로 사용한다. 새 continuation과 기존 continuation을 같은 trajectory의 4k→40k 곡선처럼 연결하지 않는다.

4k 정책과 6개 원래 상태를 과제당 20개 공개 사례로 평가한다면 **96개 정책 × 80회 = 7,680 episode**, 최악 **3.84M 평가 step**이다. 학습을 합한 환경 비용 상한은 **4.20M step**이다. 평가가 학습보다 비쌀 수 있다는 점을 예산표에서 숨기지 않는다. 실제 성공 시 조기 종료하므로 실제 비용은 별도 측정한다. 이 자료는 오프라인 개발비이며 온라인 저비용 주장에 공짜로 포함되지 않는다. gradient 추출 추가 시간도 별도 계측한다.

이 단계는 4k 신호가 새 반복의 장기 결과와 관계가 있는지, horizon·replay 정보가 단순 신호 이상을 제공하는지 확인하는 중단 가능한 점검이다. 현재 original seed가 세 개뿐인 한계는 유지된다. 신호가 잡음보다 약하거나 좋은 배분을 가려내도 예상 이득이 진단 손실보다 작으면 큰 배분 실험으로 넘어가지 않는다. 조건 선택과 임계값은 탐색 결과로 표시한다.

**단계 2: 비용을 포함한 선택 실험 — 단계 1 이후의 제안.** 예시 최소 확인 규모는 새 original seed **5개**, 200k 출발점 1개, continuation 2개, 비교법 7개, 총예산 B=40k다.

| 비교법 7개 | 목적 |
| --- | --- |
| Uniform | 진단이 필요 없는 기본 배분 |
| 개발 자료에서 선택한 고정 배분 | 단순 고정 선택으로 충분한지 |
| Failure | 현재 성능 중심 규칙 |
| Learning progress | 최근 개선 중심 규칙 |
| gradient 전이 기반 SAC 적응판 | 추가 rollout 없이 얻는 신호로 충분한지 |
| Aioli 방식의 온라인 반응 추정 SAC 적응판 | 기존 진단·동적 혼합 방법으로 충분한지 |
| horizon·학습 상태 보정과 선택적 진단 | 후보 방법의 실제 추가 가치 |

**5 × 1 × 2 × 7 = 70회 실행**, 의사결정에 쓰는 학습·진단 환경 비용 합계 상한은 **2.8M step**이다. 새 사전학습은 5×200k=**1.0M 학습 step**이다. 최종 공통 평가는 과제당 100회라면 **28,000 episode**, 최악 **14M 환경 step**이며 선택에는 노출하지 않는다. 따라서 이 예시의 전체 환경 비용 상한은 **17.8M step + 필요한 사전학습 진단 비용**이다. 이 수치는 실행 승인이 아니라 규모를 판단하기 위한 예시다.

방법 선택, 임계값, 진단 상한 0/10/20% 중 주 설정은 개발 자료에서 동결한다. 확인 자료를 보고 유리한 설정을 고르지 않는다. 위 70회는 동결된 설정 하나씩의 최소 비교이며, 세 진단 상한을 전부 별도 실행하는 제거 실험·다른 horizon·추가 과제 구성의 비용은 포함하지 않는다. 원래 seed 5개는 최소 탐색 규모이며 충분한 검정력을 보장하지 않는다. 개발 자료의 original-seed 변동에 기반한 사전 정밀도 계획을 추가한다.

평가는 original seed 단위의 짝지은 차이를 우선 제시하고 continuation과 사례는 그 아래 변동으로 구분한다. 예측 MAE·배분 순위·선택 regret, 실제 최종 macro, 최대 과제 하락, 환경 step·GPU/wall time, 오프라인 준비비를 같이 보고한다. Uniform만 이긴 것으로 충분하지 않고, 가장 강한 적응판과 고정 배분에 대한 증분을 확인한다.

후속 단계에서 두 번째 출발점, 80k 이상의 예산, 다른 task family와 benchmark로 범위를 넓힐 수 있다. 같은 MetaWorld의 B/C 구성만으로 benchmark 일반화를 주장하지 않는다. 현재 실행 중인 E3는 기존 프로토콜대로 보존하며, 이미 관찰한 결과를 새 가설의 블라인드 확인 자료로 소급 지정하지 않는다.

## 계속 진행할 기준

| 확인 결과 | 연구 판단 |
| --- | --- |
| 순위 반전이 새로운 원래 seed에서도 재현되고, 측정 가능한 상태가 오류를 설명 | 실패 조건 분석을 확대할 근거 |
| 단순 horizon·replay 보정이 상태를 분리한 검증에서 예측과 선택을 개선 | 작은 보정 모델을 실제 배분기에 연결할 근거 |
| 동일 총예산에서 강한 비교법 대비 최종 성능이 개선 | 방법 기여의 핵심 근거 |
| 예측은 좋아지지만 진단비 때문에 최종 성능이 나빠짐 | 저비용 방법 성공으로 주장하지 않고 비용 회수의 경계로 보고 |
| Aioli/gradient 적응판이 충분히 잘 작동 | 새 알고리즘보다 기존 방법의 적용 범위와 비용 검증에 연구를 한정 |
| 오류가 주로 평가·학습 잡음이며 상태 조건화가 일반화되지 않음 | 긴 horizon 보정 가설을 축소하고 큰 학습 실행을 보류 |

지금의 가장 방어 가능한 주장은 **일부 출발 상태에서 중간 성과의 순위가 최종 배분 순위로 이어지지 않고, 공개 평가를 이용한 진단은 매우 비싸다**는 것이다. 이 두 현상을 연결하여 어떤 상태에서는 저비용 보정이 가능하고 어떤 상태에서는 진단을 생략해야 하는지 밝히는 연구는 진행할 가치가 있다. 성공한 보정 알고리즘이나 benchmark를 넘어서는 일반 법칙은 앞으로 입증해야 한다.
