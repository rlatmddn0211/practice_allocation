# 오류와 수리의 범위

발견일: 2026-10-27. 66번 분석기의 합성40경로 전체 입출력 검사에서,64번에서 독립 복사한 비용 집계의 형 변환 누락을 발견했다. 합성 검사는 실제 환경 실행이 아니며 가상 성적을 과학적 결과로 사용하지 않는다.

문제는 `csv.DictReader`가 모든 셀을 문자열로 읽는다는 점이다. 사례 정규화 단계의 지역 변수에서는 `length`를 정수로 바꿨지만, 실제 비용 합산은 정규화 전 `worker_rows`를 사용했다. 따라서 `sum`의 초기 정수0과 첫 `length` 문자열을 더할 때 실패한다.

최초 무환경 자체 검사는 전이 항등식·누락 자료를, 부분 계약 검사는 완료 경로가 없는 경우를 확인했다. 이 두 경로는 실제 완료 CSV의 비용 합산 분기에 들어가지 않아 오류를 놓쳤다. 이후 전체 합성 입출력 검사가 이 누락을 잡았다. 해당 실패·수정·성공 소스 사본과 결과는66번의 독립 실행 폴더에 보존했다.

수리는 비용 합산 시 `int(row['length'])`로 명시 변환하는 한 줄이다. 원본64번은 수정하지 않았다. 학습이나 평가 결과를 바꾸거나 결과가 불리한 경로를 제외하지 않는다. 기존 연구 worker·누적 환경 비용·정책 가중치·원래 full-state 복원·seed 규약에 영향을 주지 않는다.

67번에서 기존64번의 완료 marker가 가리키는 파일만 읽어 부분 또는 최종 분석을 수행하고, 원자료를 다시 집계하는 독립 검산을 실행한다. 오류가 사라진 것과 분석 산술이 맞는 것, 과학적 근거가 확보되는 것은 각각 별개다. 부분 자료 검사는 새 실험의 과학적 결론으로 보고하지 않는다.
