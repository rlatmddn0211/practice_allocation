# 공개 점검 이력

과학 결과를 새로 산출한 작업이 아니라 기존 근거와 새 안내의 공개 점검이다. 각 실행은 새로운 결과 폴더에 실제 소스·입력 hash와 실패를 보존한다.

- 최초 Git staging은 샌드박스의 `.git/index.lock` 쓰기 제한으로 거부됐다. 요청된 게시 작업에 필요한 권한으로 재실행해 완료했다. 원자료 변경 없음.
- `20261019T030325Z_verify_47420b38`은 파일 bytes 확인 후 README의 `14_power_interruption_audit_v1/` 디렉터리 링크를 검사하다 실패했다. Git index에는 디렉터리 자체 항목이 없고 그 안의 파일이 있으므로 검사기에서 파일 링크처럼 처리한 오류다. 기존 링크는 유효했다. 디렉터리는 하위 staged 파일이 있는지를 확인하도록 검사기만 수정하고 새 출력 폴더에서 재실행한다.
- 이전 실험의 실패·중단·교체된 분석 출력은 삭제하거나 유리한 결과만 추려 공개하지 않는다. 대형 checkpoint·replay 등 기존 ignore 대상은 로컬에 보존하며 공개 범위 문서에 명시한다.

공개 검산 통과는 문서·파일 전달 무결성의 근거이며, 과학적 효과나 독립 재현의 증거 수로 사용하지 않는다.
