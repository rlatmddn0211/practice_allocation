# 공개 검산 기록

[공개 무결성 검사](results/20261020T100253Z_publication_check_256834ac/summary.json)는
검사 48,067개를 통과했다. 검산 대상은 39–53번의 staged 파일 5,262개, 74,955,713 bytes다.
공개 검사 자체의 결과 파일과 이 후속 기록은 이 목록 생성 후 추가한다.
이는 과학적 결과를 다시 검정한 수치가 아니라 Git 파일·링크·입력 보존 검사 수다.

- 39–53의 staged Git blob과 로컬 파일 bytes가 일치한다.
- 고정한 51번 명세와 49번 사례별 결과 SHA-256이 일치한다.
- 진행 중인 52번의 소스 파일은 실행 계획에 기록한 모든 hash와 일치한다.
- 주요 보고서의 로컬 링크 대상은 모두 존재한다.
- B 보고서의 `case_resample_indices.npz`, `bootstrap_draws.npz` 링크는
  기존 Git 제외 규칙에 따른 로컬 보관 자료다. 해당 원시 배열까지 공개됐다고 주장하지 않는다.
- 대형 모델·replay와 진행 중 본 실험의 작업 폴더는 이번 Git 대상에 포함되지 않는다.
- 새 환경 step와 SAC update는 0이다. 원격 조회·stage·공개 검사 동안 기존 학습은 계속했다.

첫 `git diff --cached --check`는 12개 파일의 공백 35,450곳을 보고했다.
이 중 35,446곳은 자동 생성 Matplotlib SVG 경로의 공백이고,
4곳은 원래 파일럿 문서 사본의 의도된 Markdown 두 칸 줄바꿈이다.
동결 파일을 수정하지 않고 SVG를 생성물로 표시하고 해당 Markdown 사본의 줄바꿈 공백을 허용하도록
`.gitattributes`를 구체적으로 설정했다. 소스 코드의 공백 검사를 일반적으로 끄지 않는다.

샌드박스의 Git 메타데이터 쓰기 제한으로 첫 `fetch`가 실패했고,
허용된 실행으로 재시도해 로컬과 원격 `main`의 출발점 일치를 확인했다.
공개 전후 실험의 완료 여부는 별도 기록으로 구분한다.
