# 81·82번 관측 결과 GitHub 게시

사용자가 2026-11-05에 완료된 기본 SAC 관측 결과의 GitHub 게시를 요청했다.
원격 최신 main과 74번의 연구 질문별 배치를 기준으로 별도 Git object store에서
게시본을 준비한다. 기존 runtime checkout의 HEAD/index, 원본 보고서, 코드와
체크포인트는 보존한다. 새 학습·평가·모델 실행은 없다.

보고서·그림·원 라벨·집계표·설정·코드·검증 기록을 게시하고, 대형 원본은
실제 파일과 해시·크기 목록을 연결한다. 게시하지 않은 파일을 공개된 것으로
표현하지 않는다. 원격 main이 달라지면 중단하며 force push를 사용하지 않는다.

`inventory.py`는 파일 종류와 크기를 읽는 준비 도구다.
게시 준비·검증·실제 원격 반영 기록은 고유 results 디렉터리에 남긴다.
