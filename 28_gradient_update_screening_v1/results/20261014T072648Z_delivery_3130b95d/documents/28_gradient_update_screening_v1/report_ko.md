# F04: 업데이트 방향과 크기가 최종 배분 가치를 알려주는가

**측정 신호는 존재했지만, 현재 자료에서 안정적인 추가 배분 가치로 이어지지는 않았다.** Adam 상태를 반영한 주 지표의 추가 선택 이득은 +0.065%p이고, 원래 seed 하나에서만 나타났다. 초기 성능·단기 변화·critic 진단을 통제한 예측 MAE는 6.461→6.493%p로 소폭 증가했다. 이번 두 요약 지표의 핵심 요인 채택은 보류한다.

단순 gradient 신호가 같은 후속 반복에서는 약간 개선되면서 다른 반복에는 전달되지 않는 결과도 확인했다. 따라서 ‘gradient가 충돌한다’는 관찰, ‘최종 성능을 예측한다’는 주장, ‘좋은 연습 배분을 만든다’는 주장은 분리해야 한다.

## 완료한 범위

| 항목 | 실행 규모 |
| --- | --- |
| 출발 상태 | A200/A400/B200/C200 × 원래 seed 11·12·13 = 12개 |
| 부모 이력·원래 seed 블록 | 9개 이력, 3개 seed 블록 |
| checkpoint | 부모 12개 + 20k 분기 180개 = 192개 |
| 후속 seed | A: 2101·2102·2103, B/C: 2301·2302·2303 |
| task별 replay panel | 서로 episode가 겹치지 않는 M/A 각 1,024개 |
| batch | task·panel마다 128개씩 8회; 매 batch는 시간 구간 8개를 모두 포함 |
| replay panel 항목 합 | 1,572,864개; checkpoint 사이에 자료 재사용이 있어 전역 고유 transition 수는 아님 |
| actor·critic gradient 계산 | 24,576회 |
| 복제 Adam 가상 update | 12,288회; 원본에 반영되지 않음 |
| 환경 step·지속되는 학습 update | **0 / 0** |

8개 batch와 수백 개 분기를 새로운 독립 사전학습 seed로 세지 않는다. 기존 자료의 **20k 시점** 분석이며, 원래 설계에서 제안했던 새 4k probe는 실행하지 않았다. gradient 조작을 넣는 새 학습 실험도 실행하지 않았다.

## 무엇을 계산했는가

저장된 SAC의 actor loss `mean(alpha*logpi − min(Q1,Q2))`와 critic loss `0.5*(MSE(Q1,target)+MSE(Q2,target))`를 task별로 분리했다. soft target·timeout bootstrap 규약은 실제 설치된 SAC와 replay를 따른다. 현재 저장된 entropy coefficient와 target network를 고정하고, 진단 전용 RNG로 action을 샘플링했다.

각 batch에서 actor와 critic의 task별 gradient를 따로 구해 방향 cosine·크기 비율을 기록했다. 후보 방향은 해당 20k 분기에서 **이미 관측된 부모→20k sample count 증가량**으로 가중했다. 미래 20k→40k의 실제 노출을 입력으로 쓰지 않았다. 부모 시점의 가중치는 현재 replay 구성이다.

실제 Adam의 moment·step·학습률을 복제한 뒤 가중 gradient로 가상 update δ를 만들고, 다른 episode panel의 task gradient g로 `−g·δ`를 계산했다. 이를 평가 panel의 task별 **개별 loss RMS**로 나누고 네 과제·여덟 batch를 평균한다. actor와 critic에서 각각 한 값, 총 두 개가 주 특징이다. 양수는 해당 고정 loss의 국소적 하락 예측을 뜻한다. 성공률의 gradient 또는 실제 미래 성공률 증가량은 아니다.

이는 **고정 상태의 부분 업데이트 진단**이다. 실제 SAC 한 step처럼 critic을 먼저 바꾼 뒤 actor gradient를 새로 계산한 완전한 결합 업데이트가 아니다. entropy·target network도 가상으로 갱신하지 않는다. ‘실제 Adam 상태를 반영했다’와 ‘실제 후속 학습 전체를 재현했다’를 혼동하지 않는다.

미리 지정한 비교는 다음과 같다.

1. task 간 raw cosine 평균 두 개.
2. gradient 크기와 관측 노출을 반영한 혼합 방향과 별도 panel gradient의 정렬 두 개.
3. Adam과 update 크기까지 반영한 정규화 loss 하락 예측 두 개: **주 특징**.
4. M/A 역할을 반대로 한 재측정, 동일 task 가중치의 Adam, F05 대조 특징을 뺀 기준선: 보조 민감도.

각 비교는 사전에 정한 두 특징만 추가했다. 관찰된 좋은 조합을 사후 주 결과로 교체하지 않았다.

## 신호의 반복성과 관찰

아래는 180개 20k 분기에서의 기술적 요약이다. 상관은 서로 독립이지 않은 분기 간 기술통계이며 p-value를 붙이지 않았다.

| 측정 | actor | critic |
| --- | ---: | ---: |
| M→A와 A→M 주 지표의 Spearman | 0.827 | 0.944 |
| 두 panel 방향의 평균 부호 일치 | 97.78% | 92.78% |
| batch에 따라 주 지표 부호가 섞이는 분기 | 23/180 | 51/180 |
| raw task 쌍 cosine이 음수인 평균 비율 | 35.59% | 29.39% |
| task gradient 최대/최소 norm 비율의 중앙값 | 2.24배 | 5.43배 |
| 평균 Adam 하락 예측이 음수인 분기 | 3/180 | 27/180 |

과제 간 반대 방향과 크기 차이가 측정됐고, 특히 critic의 국소 업데이트 평가에는 batch 의존성도 있다. 이것만으로 실제 망각의 원인, critic 오류의 크기, 바람직한 성공률 변화라고 명명하지 않는다. 모든 panel은 이미 학습에 사용된 replay에서 뽑았으며, episode를 나눠도 독립 환경 일반화 검사는 아니다.

## 미래 예측·선택 검증

평가는 [F01 검증](../27_success_retention_screening_v1/report_ko.md)과 동일한 기존 148,800 episode 행을 사용한다. task별 hash 분할 D50/O50, 원래 seed 전체 제외, 학습 fold만의 표준화, 고정 ridge penalty 1, 동일 가중 macro 목적을 유지했다. 입력은 20k까지, 예측 목표는 같은 분기의 D40−D20이다.

주 기준선 **CriticBase**는 네 task 각각의 초기 성공률·변화·순하락에 F05의 reward scale·target scale·정규화 TD 잔차·twin gap을 더한다. F01의 사례 교체 특징은 넣지 않는다. 원래 seed가 다른 학습 자료로만 예측기를 적합한다.

동일 후속 seed의 다섯 20k 분기 중 예측 최종 macro가 큰 것을 고르고, 그 **실제 같은 40k 분기**를 O에서 채점했다. A/B/C 동일 가중, A 안의 두 출발 시점 동일 가중을 쓴다.

| 방법 | 최종 macro 성공률 | CriticBase 대비 | O40 예측 MAE |
| --- | ---: | ---: | ---: |
| Uniform | 42.398% | −2.722%p | — |
| 실패율 집중 | 41.713% | −3.407%p | — |
| 다른 원래 seed의 좋은 고정 배분 | 42.898% | −2.222%p | — |
| Greedy20 | 45.287% | +0.167%p | — |
| CriticBase | 45.120% | 기준 | 6.461%p |
| + raw cosine | 45.213% | +0.093%p | 6.407%p |
| + 크기·노출 반영 raw 방향 | 45.380% | +0.259%p | 6.385%p |
| **+ Adam 주 지표** | **45.185%** | **+0.065%p** | **6.493%p** |
| + 반대 panel의 Adam | 45.269% | +0.148%p | 6.459%p |
| + 균등 task 가중 Adam | 45.185% | +0.065%p | 6.492%p |

주 지표는 36개 선택 중 **3개**를 바꿨다. 원래 seed 11/12/13의 추가 이득은 **+0.194 / 0.000 / 0.000%p**이고, A200/A400/B200/C200에서는 **−1.833 / +2.222 / 0.000 / 0.000%p**다. 시점별 득실이 상쇄됐다. O 사례만 재표집한 조건부 95% 구간은 **[−0.167, +0.315]%p**다. 모델·훈련·진단 선택 변동은 이 구간에 포함되지 않는다.

최악 task 하락의 선택 평균은 CriticBase 11.741→주 지표 10.481%p로 줄었지만 이는 보조 관찰이다. 현재 동일 가중 macro라는 목적을 그 결과에 맞춰 바꾸지 않았고, 보존 손실 개선을 독립적으로 검증했다고 말하지 않는다.

## 다른 반복으로 옮겼을 때

다른 두 후속 반복의 20k 정보를 평균해 남은 한 반복의 40k 배분을 고르는 보조 분석을 수행했다.

| 추가 특징 | 같은 반복의 추가 이득 | 다른 반복으로 전달한 추가 이득 |
| --- | ---: | ---: |
| raw cosine | +0.093%p | **−0.444%p** |
| 크기·노출 반영 raw 방향 | +0.259%p | **−0.500%p** |
| Adam 주 지표 | +0.065%p | +0.111%p |
| 반대 panel의 Adam | +0.148%p | **−0.407%p** |
| 균등 가중 Adam | +0.065%p | +0.111%p |

주 Adam의 교차 반복 최종 성공률은 43.815%, 기준선은 43.704%다. 조건부 O 구간은 추가 이득 **[−0.009, +0.241]%p**다. 주 지표의 작은 양수 결과도 panel을 바꾸면 유지되지 않았다. 균등 가중 Adam은 주 지표와 같은 배분들을 골랐다. 이번 자료에서 관측 노출 가중의 추가 선택 효과도 확인되지 않았다.

F05 대조를 빼고 과제별 성능 Profile에 Adam을 추가하면 같은 반복에서 **+0.380%p**, 다른 반복에서는 **0.000%p**다. 단순 기준의 같은 반복 결과만으로 후보를 승격하지 않는다. 대조 변수 추가는 고정 ridge의 적합 자체도 바꾸므로 이를 F05의 인과적 조절 효과라고 해석할 수도 없다.

## 비용·기술 검증·실패 보존

본 측정은 wall **334.47초(약 5.6분)**, CPU **168.22초**, CUDA event 구간 합 **211.27초**였다. CUDA 수치는 진단 계산 구간의 경과시간으로 GPU의 순수 kernel 점유 시간이나 사용률과 같지 않다. 분석은 **1.17초**였다. 예비 실행·검산·실패 시도는 별도 실행이며 이 본 측정 비용에 숨겨 넣지 않았다. F05 특징은 이전 측정값을 재사용했고, 실제 배포에서 그것을 새로 계산할 추가 비용을 여기서 측정한 것은 아니다.

진단용 가상 Adam 12,288회는 복제 파라미터에서만 실행했다. 신규 RL 환경 step과 **원본에 지속되는 learner update**는 모두 0이다. checkpoint 파일, 학습·optimizer 상태, replay를 전후 hash로 확인했다. 학습에 재사용 가능한 checkpoint를 새로 쓰지 않았다.

온라인 비용을 가정하면 다섯 20k probe가 100k 학습, 선택한 분기의 남은 20k까지 **120k**가 필요하다. 부모 D 평가 평균 62,710.89 step, probe D 평가 평균 309,081.94 step도 소요된다. 교차 반복은 **240k 학습**과 probe D 평가 618,163.89 step이다. 40k 총예산의 실제 배분기 성능으로 해석할 수 없다. 최종 O 채점과 개발 자료 생성비는 배포 시점 진단비와 별도로 남아 있다.

검증은 모든 batch의 Gram 행렬·교차 내적·Adam 내적으로 특징을 재계산하고, 별도 backward 구현·Adam 공식·고정 noise finite difference로 네 구성·출발점의 대표 checkpoint 8개를 확인했다. [최종 측정 검산](results/20261014T071809Z_verify_measurements_9b3c92e4/summary.json)은 87,608개 검사를 통과했다. 예측 검산은 원본 평가부터 다시 읽어 다른 선형 풀이로 전체 1,440개 예측과 864개 선택 행, 조건부 구간을 확인했으며 26,858개 검사를 통과했다. 주 효과 기준을 통과하는지와 구현 검사를 통과하는지는 별개다.

전체 수치 검산에서 작은 float32 반올림 차이와 이후 JSON 저장 형식 문제가 각각 발생했다. **두 측정 검산 실패 디렉터리를 보존**하고 검산을 수정해 새 디렉터리에서 재실행했다. 이후 산출물 정리 검사의 문자열 탐색 오탐도 AST 호출 검사로 고치고 보존했다. gradient·주 예측·선택 결과는 변경하지 않았다. 저장 실패 시도의 정확한 최종 CPU/wall 요약은 없으므로 전체 비용을 정확히 합산했다고 주장하지 않는다. [실패 상세](technical_failures_ko.md).

## 현재 판정과 연구에 주는 의미

평균 추가 이득 1%p 이상·원래 seed 두 블록 이상 양수라는 선별 조건을 주 지표가 충족하지 못했다. **F04의 이번 요약 방식은 핵심 요인 채택을 보류한다.** gradient 방향·크기라는 후보 전체의 가능성을 부정하는 판정은 아니다.

이번 결과는 ‘측정 가능한 충돌’이 ‘남은 예산의 좋은 배분 기준’으로 자동 연결되지 않는다는 점을 구체화한다. 후속 반복에 따라 역전되고, local loss는 dense reward·critic·entropy의 대리목표이며 macro 성공률과 동일하지 않다. 그래도 방향 신호를 다시 추적하려면 더 작은 실제 probe에서 반복 가능한 특징을 먼저 고정하고, 새 원래 seed에서 현재 성공률·단기 변화 이상의 추가 선택 이득을 확인해야 한다. gradient projection 같은 학습 개입의 기전 검증은 별도 실험이며 이번에 수행하지 않았다.
