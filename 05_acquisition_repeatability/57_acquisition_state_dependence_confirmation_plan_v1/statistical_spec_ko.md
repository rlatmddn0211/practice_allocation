# 사전 분석 명세 — 재현과 경쟁 설명을 같은 새 미래에서 확인

57번은 사용자 제안을 구체화한 **실행 전 설계와 기존 참조 자료 준비**다. 이후 학습 실행을 승인하거나 원래 단계의 보류를 해제하지 않는다. 이 명세를 바꾸려면 새 확인 결과를 보기 전에 이유·버전·지문을 남긴다. 결과를 본 뒤 바꾼 절차는 새 탐색으로 분리한다.

## 1. 두 자료의 역할

부모p, 과제t, 두 prefix 상태s∈{1,2}, 사례i를 둔다. 기존 old_J40와new_J40는 이제 **참조 미래F1·F2**로 부른다. 이번에 제안하는 미래는 **F3·F4**다. F2가 과거 문서에서 ‘새 미래’였다는 이름 때문에 확인 자료와 섞지 않는다.

I_pt={i:J8_1i=0 그리고 J8_2i=0}는 확인 전에 고정한다. 같은 부모·과제·case의 seed와 initial_state_hash가 같음을 검증한다. 부모별 bank가 다르므로 서로 다른 부모의 case번호를 같은 사례로 묶지 않는다.

새 미래는 동일한10개 전체 상태에서 각각 직접 복원한다. F3를 학습한 뒤 그 결과에서F4를 이어 학습하지 않는다. 각 미래에 actor/critic/target/optimizer/entropy/replay/collector/일정 위치/학습 수치를 보존하고 활성 난수만 독립된 의사난수 root로 교체한다. 52번의 기술 복원 원칙을 독립 실행 버전에서 다시 확인한다.

최종 정책은 같은 O100에서 평가한다. 추가8k 정책 평가나 중간 성능 평가를 주실험에 넣지 않는다. 참조 표의 적격 여부는 이미 측정된8k 결과다. 새 미래 결과를 적격 사례 선정·모형 적합·축소율 조정에 쓰지 않는다. 이는 **새 학습 미래에 대한 확인**이며 새 평가 사례에 대한 일반화 실험은 아니다.

## 2. 현상 지표와 분모

새 미래F3를 쌍의 왼쪽, F4를 오른쪽에 놓고 부모×과제마다 T_ab=m_ab−n_3,a n_4,b/N을 계산한다. D_pt=(T11+T22−T12−T21)/2다. 네 쌍은 같은 정책·사례를 공유하므로 독립 반복으로 세지 않는다.

주 관심 과제는 결과를 보고 선정한 **DC·PU**다. 과제 선정 자체는 탐색의 산물임을 공개하고 새 미래로 확인한다.

\[
D_p^{\rm focus}=\frac{D_{p,DC}+D_{p,PU}}4,
\qquad D^{\rm focus}=\frac15\sum_p D_p^{\rm focus}
=100\frac{\sum_{p,t\in\{DC,PU\}}D_{pt}}{2000}.
\]

분모2,000은 기존5부모×4과제×100슬롯이다. 2과제만 남긴다고 분모를1,000으로 바꿔 값이 두 배 커지게 하지 않는다. 부모당 분모는400슬롯이다. N=0이면 슬롯 집계의 기여0이며, 해당 적격 사건률은NA다. 별도 과제 전체 단위를 보고할 때에는 분모를 명시하고 주 수치와 혼용하지 않는다.

56번의 탐색 관측으로 같은 정의를 계산하면 DC·PU 기여는 약+0.191%p이며, 전체4과제+0.199%p와 구분된다. 이 참조 수치는 확인 결과나 검정력 추정치가 아니다.

보조 결과는 모든4과제D, 각 과제D, 공통 성공 집합의 상실D, J0 층화, 사건량·N·가능한 중첩 하한/상한·T_max, 최종 성공률·획득·상실량이다. 어떤 보조 결과가 유리하다는 이유로 주 판정을 교체하지 않는다. 상실 모형 탐색을 추가하지 않는다.

## 3. 경쟁 설명을 약하게 만들지 않는 모형

목표는 새 알고리즘 제안이 아니라 **기존 미래에서 알아낸 어떤 정보가 새 미래에도 남는가**다. 단순히 상태마다 intercept만 다른 모형보다 유연한 단순 설명을 사용한다. 아래 모형은 참조 자료에만 맞춘다. 참조 자료의 적합도를 성공 근거로 보고하지 않는다.

### M0: 공통 사례 등급과 상태별 반응 곡선

R=2 참조 미래에서 상태s의 성공 수를 k_si∈{0,1,2}, 두 상태의 합을 c_i=k_1i+k_2i∈{0,1,2,3,4}로 둔다. c가 높을수록 참조에서 공통으로 획득되기 쉬웠던 등급이다. 이는 **네 번의 이진 관측으로 만든 거친 대리량**이며 실제 잠재 난이도를 정확히 안다는 가정이 아니다.

부모×과제별로 관측된 c등급만 사용한다. n_c는 해당 사례 수, K_sc=Σ_i:c_i=c k_si다. 각 상태마다 다음 확률 v_sc를 맞춘다.

\[
\min_{0<v_{sc}<1}\ -\sum_c\{(K_{sc}+1)\log v_{sc}+(2n_c-K_{sc}+1)\log(1-v_{sc})\},
\qquad v_{s,c}\le v_{s,c'}\quad(c<c').
\]

각 관측 등급에 성공1·실패1의 가상 관측을 고정하고, weighted PAVA로 단조 제약을 적용한다. 등급이 비어 있으면 새로운 가상 등급을 만들지 않는다. p0_si=v_s,c_i다. 두 상태는 서로 다른 비선형 단조 곡선을 갖게 하므로, 공통 난이도 순위가 같아도 전체 능력·반응 강도·포화가 다른 상황을 허용한다. PAVA는 기존 등위 회귀 기법을 사용하는 것이며 새 학습 방법이 아니다. [de Leeuw 등 원문](https://www.jstatsoft.org/article/view/v032i05)

### M1: 같은 등급 안의 상태별 사례 반응

같은 c집단 안에서 h_i=k_1i/2−mean_{j:c_j=c_i}(k_1j/2)로 정의한다. 두 상태의 합c가 같으므로 상태2의 중심화 편차는−h_i다.

\[
p1_{1i}=p0_{1i}+\lambda_c h_i,\qquad
p1_{2i}=p0_{2i}-\lambda_c h_i.
\]

기본축소율은 **0.25**로 고정한다. λ_c는0.25와 모든 사례·두 상태의 확률이[0,1]에 머무는 상한 중 최소값이다. h=0이면 변화0이다. 결과를 보고 λ를 늘리거나 후보를 탐색하지 않는다. 이 수치는 최소한의 추가 정보만 넣기 위한 설계 선택이며 최적 축소율이라는 주장이 아니다.

이 정의는 다음을 보존한다.

- 각 상태·공통등급 안의 평균 획득확률은 M0와 같다.
- 각 사례의 두 상태 평균 획득확률도 M0와 같다.
- 바뀌는 것은 같은 등급 안에서 어느 사례가 어느 상태에 상대적으로 유리한지다.

따라서 M1의 개선을 단순한 전체 획득량 재보정과 분리하기 쉽다. 다만 **정해 둔 공통 등급·단조 보정 모형을 넘어서는 정보**라는 한정된 비교다. 모든 가능한 잠재 난이도 모형이나 신경망 기전을 배제하지 않는다. 등급이0 또는4인 사례처럼 참조 반응 차이가 없는 곳에는 추가 신호가 생기지 않는다.

## 4. 예측 평가 하나: Brier 오차

확인 미래f∈{3,4}의 결과 Y_sfi에 대해 loss=(p_si−Y_sfi)^2다. 이진 확률 예측에 적절한 scoring rule이며, 이 문서는 작을수록 좋은 오차 방향으로 쓴다. [Gneiting·Raftery 원문](https://sites.stat.washington.edu/people/raftery/Research/PDF/Gneiting2007jasa.pdf)

부모p의 DC·PU 공통 실패 사례들을 합친 수를 N_p라 하면,

\[
BS_p(M)=\frac1{4N_p}\sum_{t\in\{DC,PU\}}\sum_{i\in I_{pt}}\sum_{s=1}^2\sum_{f=3}^4(p^M_{si}-Y_{sfi})^2,
\quad G=\frac15\sum_p[BS_p(M0)-BS_p(M1)].
\]

부모 안에서는 해당 DC·PU 사례를 동일 가중하고 부모 사이에서는 동일 가중한다. 이는 모든 사례가 많은 부모를 더 큰 독립 표본으로 세지 않기 위해서다. D의 고정 슬롯 단위와 Brier의 공통 적격 사례 단위는 다르며, 숫자 크기로 서로 비교하지 않는다. N_p=0이면 그 부모를 조용히 제외하지 않고 해당 주 투자 판정을 계산 불가로 둔다.

G>0이면 추가 설명이 더 정확하다. F3·F4 각각의 G, 부모별·과제별G와 각 모형의BS도 공개한다. 분류정확도·AUC·log-loss 중 유리한 점수를 골라 주 판정을 바꾸지 않는다. 모델이 예측한 기대D=N/2 Var_i(p1_i−p2_i)는 보조 기술량으로만 연결할 수 있다. 모형의 예상D와 관측D 차이를 ‘기전이 설명한 비율’이나 독립 사례 생성 모형의 확증 p값으로 바꾸지 않는다.

기존 완성 미래 결과를 입력으로 사용한 모형이므로 온라인8k 선택기나 무료 진단 신호가 아니다. 그 사용 목적은 사례 반응의 반복성 측정이다.

## 5. 불확실성과 고정 투자 판단

사례 재표집20,000회(seed570303)는 부모×과제×공동 이력(J0,J8_1,J8_2) 안에서 같은 수를 복원추출하고, 같은 인덱스를 모든 상태·예측·새 미래에 적용한다. D와G를 매번 짝지어 다시 계산하되 **모형은 재적합하지 않는다**. 개별2.5/97.5percentile 구간이다. 부모3,125개 재표집과 모든 부모 제외 결과도 계산한다.

사례 구간은 관측된 기준 이력·참조 모형·새 최종 정책에 조건부다. 새 미래 두 개로 미래분산을 정밀 추정한 것이 아니다. 부모 구간은 다섯 개발 부모의 기술적 재표집이며 독립 확증이 아니다. 이 첫 묶음의 목적은 기존 상태에서의 **새 미래 확인과 다음 투자 판단**이다. 모집단 또는 새 부모에 대한 확인은 둘째 묶음에서 별도로 한다.

다음 수치는 **사용자 검토를 위한 제안 기준**이다. 이전 선택기의+1%p를 가져오지 않는다. D0.10%p는 고정 슬롯 분모에서 쌍 평균 초과 중첩 약2건에 해당한다. G0.001은 평균 제곱확률오차0.001의 감소이며 성공률0.1%p와 같지 않다. 아주 작은 양수만으로 계속 투자하지 않기 위한 연구비 판단 문턱이고, 검정력·최소과학적중요도의 보편적 정답은 아니다.

새 부모 실험을 설계할 투자 근거로 채택하려면 다음을 모두 충족하도록 제안한다.

1. 20개 새 미래가 사전 명세대로 완료되고 모든 기술 무결성 검사를 통과한다.
2. D_DC+PU≥0.10%p, G≥0.001이다.
3. D·G 각각의 조건부 사례구간 하한이0보다 크다.
4. 어떤 부모를 하나 제외해도 D·G의 나머지 부모 평균이0보다 크다.
5. F3와F4 각각에서 G>0이다.

부모 기술 구간을 추가 통과 문턱으로 사용하지 않는다. 위 결합 기준은 투자 판단용이며 사례들을 독립 학습 반복으로 간주한 통계적 확증이라고 부르지 않는다. 다섯 부모·두 미래의 한계가 남으므로 충족해도 논문 완성이나 게재를 보장하지 않는다.

**실패 해석도 고정한다.** D가 반복되어도 G가 유의한 양수가 아니라는 이유만으로 ‘단순 설명이면 충분’이라고 결론 내리지 않는다. 구간이 넓으면 미확정이다. G상한이0.001보다 작으면 정해둔 M1의 추가 이득이 그 문턱보다 작다는 근거로만 해석한다. 한 번 실패했다고 모든 상태 반응 정보가 없다는 뜻도 아니다. 기준 미충족 시 자동 재학습·모형 교체·부모 확대 없이 제한된 결론을 기록한다.

## 6. 두 번째 묶음과 논문 완료 조건

첫 묶음이 지지될 때만 새 부모 수·seed·전체예산·종료규칙을 고정한다. 첫 단계 사례bootstrap 폭만으로 표본 수를 정하지 않는다. 부모 변동과 두 미래의 제한된 정보, 목표 효과·정밀도, 자원 상한을 함께 평가하고 근거가 부족하면 불확실성을 그대로 둔다. 결과가 유리해질 때까지 부모를 늘리지 않는다.

새 부모마다 참조 미래가 없으므로, **두8k상태×(참조2+확인2) 미래**가 필요하다. 부모200k+prefix16k+미래256k=학습472k다. 적격 집합을 정할8k정책2개와 미래정책8개 총10정책을 O100×4과제로 평가하면 상한2M, 합계2.472M/부모다. 부모0k 자체 O100은 필수 아님; 성공 이력 보조 분석에 추가한다면0.2M/부모를 따로 더한다.

새 부모의 참조2미래로 같은 절차를 맞추고 예측지문을 고정한 뒤 확인2미래를 평가한다. 이는 **관계·절차의 새 부모 재현**이며 옛 부모에 맞춘 사례별계수를 새 bank 사례에 그대로 전이한 실험은 아니다.

경계 조건을 주장하려면 상태의 특성을 후속 결과 이전 자료로 정의해야 한다. 사용할 로그 변수·구간·정규화·임계값 및 지원 부족 처리 규칙은 둘째 묶음 실행 전에 별도 고정한다. 지금 critic/replay를 원인이나 경계 조건으로 선정하지 않는다. 조건부 경계를 검증할 관측 범위가 없으면 경계 주장을 하지 않는다.

논문 핵심은 (1)새 미래 재현, (2)명시한 단순 설명과 추가 사례 반응 정보의 구분, (3)새 부모에서 유지되는 범위 또는 반복되는 경계다. 원인 개입·선택기·새 알고리즘은 이 세 주장에 필수로 추가하지 않는다. 둘째 묶음까지 범위가 명확해지면 집필·필수 보완으로 전환한다. 제목의 일반성은 확인한 SAC·과제군·예산 범위를 넘지 않는다.
