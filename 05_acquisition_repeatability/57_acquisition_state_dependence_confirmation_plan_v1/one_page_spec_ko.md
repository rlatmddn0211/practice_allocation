# 논문 질문과 첫 확인 실험 — 한 장 명세

2026-10-22 / **설계·참조 자료 준비만 승인 범위로 해석. 새 학습 실행·예약 없음.**

**잠정 논문 질문:** 같은 규칙으로 추가 강화학습했을 때, 어떤 사례에서 성공을 얻는지는 출발 상태에 얼마나 의존하며, 그 의존성은 새로운 학습 미래와 새로운 부모·상태에서도 유지되는가?

**핵심 주장 후보:** 두 8k 상태 모두 실패한 사례 중에는, 공통 사례 성향과 상태별 전반적 반응 차이를 넘어 참조 미래에서 알아낸 상태별 획득 반응이 새 미래에도 남는다. 사실로 확정한 주장이 아니라 이번 실험의 판정 대상이다. 획득을 중심으로 두고 상실은 보조 분석으로 유지한다. 새 선택기·새 RL 알고리즘·인과 개입은 논문의 필수 단계가 아니다.

| 항목 | 실행 전에 고정할 명세 |
|---|---|
| 출발점 | 기존 부모41011–41015 × prefix4201/4202 = 전체10개8k 상태 |
| 확인 자료 | 각 상태에서 새 미래F3·F4, 총20개; 각각 원래8k 전체 상태에서32k BP dose625 지속 |
| 참조 자료 | 기존 미래F1·F2는 설명 모형 적합에만 사용. 주 중첩 대조는 F3·F4만 사용 |
| 평가 | 같은 부모별 O100, 최종20정책 × 4과제 × 100사례 × 최대500step |
| 주 관심 범위 | DC·PU, 두 상태 공통 실패 사례. DO·BP와 상실은 사전 지정 보조 결과 |
| 현상 지표 | 동일−교차 초과 중첩 D_DC+PU. **분모는 기존4과제 전체2,000슬롯으로 유지**. 성공률 이득 아님 |
| 단순 설명 M0 | 기존4관측의 합계로 정한 공통 사례 등급에, 각 상태의 서로 다른 단조 획득확률 곡선을 허용 |
| 추가 설명 M1 | 같은 공통 등급 안에서 관찰된 상태별 사례 반응 차이를 보수적으로 추가. 각 상태·등급의 평균 예측과 각 사례의 두 상태 평균은 M0와 동일하게 유지 |
| 설명 평가 | 새 두 미래의 **Brier 오차 하나**. G=BS(M0)−BS(M1), 부모 동일 가중. 양수면 M1 유리 |
| 누출 방지 | 적격 사례·모형·축소율·예측 CSV·seeds·소스 hash를 새 미래 생성 전에 고정. 새 결과로 재적합하지 않음 |
| 본 환경 예산 | 학습640,000＋평가상한4,000,000 = **4,640,000step** |
| 기술 포함 제안 상한 | 별도기술10,000 포함 **4,650,000step**. 자동 재시도 예산0 |

**새 부모 설계로 투자할 제안 기준:** 기술 무결성 통과 후, D_DC+PU≥**0.10%p**, G≥**0.001**이며 각각 조건부 사례구간 하한>0, 모든 부모 하나씩 제외 평균>0, F3·F4 각각의 G>0을 모두 요구한다. **이 수치는 새 투자 판단을 위한 제안값이며 검정력 보장·성공률 기준·사용자 승인값이 아니다.** D와 G는 다른 단위다. 부모 구간과 지원 범위를 함께 공개하고, 작은 사례 오차를 학습 미래의 확실성으로 바꾸지 않는다.

| 결과 | 다음 판단 |
|---|---|
| D 재현 미확보 또는 불확실 | 현재 방향 투자 축소·보류. 자동으로 미래·부모를 늘리지 않음 |
| D는 반복되나 G 미확보 | 검토한 추가 설명의 이득 미확보. 모든 단순 설명이 충분하다는 증명은 아님 |
| 두 기준과 분산된 지지 확보 | 두 번째 묶음의 새 부모 수·예산·사전 상태 조건을 정하고 별도 실행 판단 |
| 새 부모에서 범위 또는 일관된 경계 확인 | 독립 재현·설명 비교·적용 범위 세 주장으로 논문 본문 구성 |

**두 번째 묶음:** 새 부모마다200k 사전학습＋두8k prefix＋각 상태 참조2·확인2미래가 필요하다. 부모당 **학습472k＋평가상한2.0M=2.472Mstep**, 기술비용 별도. 부모 수는 지금 임의로 정하지 않는다. 첫 묶음의 부모·미래 변동, 목표 정밀도, 허용 예산으로 유한한 규모와 종료 규칙을 새 결과 전에 정한다. 원래0k 부모 정책의 별도평가를 추가하면 부모당최대200k가 더 든다.
