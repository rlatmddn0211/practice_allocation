# 56 — 동일 상태·교차 상태 대조의 정의와 55번 해석 보완

2026-10-22 사용자 피드백에 따른 기존 자료 분석이다. 55번은 보존한다. 이 명세는 **56번 대조를 처음 계산하기 전** 작성했지만, 같은 자료의 과거 결과를 이미 본 뒤 만든 탐색적 분석이다. 독립적인 사전등록이나 확인 실험으로 부르지 않는다.

## 질문과 비교 집합

여러 학습 상태에 공통된 사례별 획득 성향을 넘어, 출발 상태와 연결된 추가 사례 반응 구조가 있는가? 부모 41011–41015 각각의 두 8k 상태를 S1(prefix4201), S2(prefix4202)로 둔다. 획득은 **두 상태 모두 실패**, 상실은 **두 상태 모두 성공**한 O100 사례만 사용한다. 성공 여부가 다른 사례는 제외하고 그 수를 공개한다. 부모×과제 20개 층에서 각 층의 같은 사례 집합으로 네 쌍을 모두 계산한다.

| 종류 | 기존 미래 | 새 미래 |
|---|---|---|
| 동일 상태 | S1 | S1 |
| 동일 상태 | S2 | S2 |

55번의 전체 적격 집합 중첩과 제한된 공통 집합의 교차 중첩을 직접 빼지 않는다. 동일 상태 중첩도 공통 집합에서 다시 계산한다. 네 쌍은 정책·사례를 공유한다. 주 독립 단위는 부모 5개이며 네 쌍을 독립된 네 반복으로 세지 않는다.

## 점수·가중·단위

각 쌍에서 N은 공통 적격 사례 수, n1/n2는 두 미래의 사건 수, m은 공통 사건 수다.

T = m − n1 n2 / N.

동일 상태 = (T11 + T22)/2, 교차 상태 = (T12 + T21)/2, D = 동일 상태 − 교차 상태.

주 보고 단위는 **100 × ΣD / 2,000 = ΣD / 20**이다. 부모·과제에 동일 가중한 전체 부모×과제×사례 슬롯 대비 초과 중첩 차이(%p)이며, 성공률 개선이나 선택기 이득이 아니다. ΣD 및 두 쌍 평균 중첩 수도 함께 적는다. 평균 중첩 수는 반 건 단위일 수 있고, 네 쌍을 합친 고유 사례 수가 아니다. 공통 적격 N으로 나눈 비율은 보조 기술량으로만 제시한다. N=0인 층은 전체 슬롯 집계에서 0 기여이며, 적격 비율은 정의하지 않는다.

J0로 추가 층화한 기대 중첩을 보조적으로 계산한다. 기본 분석을 바꾸거나 유리한 결과를 선택하지 않는다. 부모별·과제별 결과, 부모 하나씩 제외 결과, 원래 적격 집합 대비 공통 집합 범위를 모두 제시한다.

## 초과 중첩이 뜻하는 것과 뜻하지 않는 것

‘기대 중첩’은 각 층의 사건 수를 보존하면서 사례 라벨을 무작위 대응시키는 기준이다. 모든 사례의 획득 확률이 같다는 현실적 사실을 전제하지 않는다. 독립적인 두 미래에서 사례 i의 사건 확률이 각각 p_i, q_i라면, E[T] = N Cov_i(p_i,q_i)이다. 여기서 공분산은 N개 사례에 대한 분모 N의 유한 집합 공분산이며, 두 미래의 **벡터 전체가 독립**이라는 가정을 쓴다. p_i=q_i이면 E[T]=N Var_i(p_i)이다. 같은 미래 내부의 사례들이 서로 독립일 필요는 없다.

따라서 양의 T는 공통된 사례별 사건 성향만으로도 생긴다. 특정 학습 상태의 고유 효과, 미래 간 의존성, replay의 인과 효과를 분리한 값이 아니다. ‘사례 난이도 대 학습 상태’를 배타적인 설명으로 두지 않는다.

대조의 계산 검산에는 다음 항등식도 사용한다. a1/a2는 두 상태의 기존 미래 사건 벡터, b1/b2는 새 미래 사건 벡터다.

D = 1/2 × [Σ(a1−a2)(b1−b2) − Σ(a1−a2)Σ(b1−b2)/N].

즉, 같은 사례에서 **상태 사이의 반응 차이**가 기존·새 미래에 공통으로 남는지를 묻는다. 두 시기의 상태별 확률 차이가 같고 각 쌍의 미래가 독립이라는 추가 가정 아래 기대 D는 N/2 × Var_i(p1_i−p2_i)이다. 실제 한 쌍 관측에서 D가 음수일 수도 있다. 이 가정식은 관측된 D가 곧 모집단의 기전 추정치임을 뜻하지 않는다. 상태에 따른 사건 확률의 일정한 증가처럼 중심화에서 제거되는 차이도 있어, D=0은 모든 상태 효과의 부재가 아니다.

## 상실의 측정 여지

각 쌍에서 max(0,n1+n2−N) ≤ m ≤ min(n1,n2), T_max = min(n1,n2)−n1n2/N이다. 한 미래의 사건 수가 0 또는 N이면 T는 반드시 0이다. 큰 상실이 두 미래에서 반복되어도 그 안의 특별한 취약 사례를 더 구별할 여지가 없을 수 있다. N, 사건 수, m의 하한·상한, T_min/T_max를 모든 쌍에서 공개한다. T/T_max 같은 불안정한 비율로 주 분석을 대체하지 않는다.

55번의 상실 T≈0은 사건 총량을 조건으로 한 하위 사례의 초과 중첩 결과다. 전체 상실이 반복되지 않는다거나 획득이 본질적으로 더 안정적이라는 결론을 내리지 않는다. 성공 이력의 집계 차이도 조정·가중·부모에 민감했으므로 보편적인 ‘최근 성공 취약성’은 중심 가설로 채택하지 않는다.

## 불확실성·난수·판단
