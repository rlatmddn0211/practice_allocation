# 실행 전 보완의 상태와 근거

2026-10-22. [57번 설계 기록](../57_acquisition_state_dependence_confirmation_plan_v1/evidence_record_ko.md)의 후속 수정이며, 기존 기록을 보존한다. [25번 원장 원칙](../../02_learning_signals_and_conditions/25_candidate_factor_evidence_register_v1/README.md)에 따라 준비·검사 완료와 과학적 결론을 구분한다.

| 대상 | 실행 상태 | 과학적 결론 |
|---|---|---|
| 질문·주장 범위·가중치·판정표 | 수정 명세 완료 | 새 결과가 아니라 확인할 주장과 해석의 경계 |
| 고정 M0/M1·G 상한 점검 | 기존 파일 계산·독립 검산 완료 | 구조적 불가능성은 발견하지 않음. 예측력·검정력·실제 도달 가능성 미확인 |
| F3/F4의 D/G | **미실행·미예약** | 미측정; 통과/실패 판정 없음 |
| 새 부모 적용 범위 | 조건부 계획, 부모수·총예산 미정 | 미측정 |
| 선택기·인과 개입 | 이번 범위 밖 | 기존 보류 유지 |

**비교와 수치.** 기준은 참조 네 관측 합계의 0–4등급과 부모×과제×상태별 단조 곡선 M0다. M1은 같은 등급 안의 상태별 상대 반응을 추가하되 두 평균을 보존한다. 주 G는 부모 안 DC·PU 적격 사례를 합쳐 평균하고 부모 5개를 동일 가중한다. 548개 중 49개 사례에서만 예측이 다르며 모두 PU(41011/41013/41015의 29/11/9개)다. 전체 G의 이진 결과 상한은 0.004720526740, 최저 부모 제외 상한은 0.001231242916이다. 전체 상한의 79.1338%가 41011에서 나오며 실제 효과의 집중도는 아직 모른다.

**불리하거나 제한적인 결과.** DC와 41012/41014에서는 두 예측이 같아 G가 항상 0이다. 이 범위에 효과가 없다는 실험 결과가 아니다. DC의 중첩 현상과 PU의 예측 정보를 같은 과제에서 설명했다고 합치지 않는다. 수정된 49개로 주 분모를 줄이지 않는다. M1의 승리도 모든 공통 잠재 난이도 설명을 배제하지 못한다. 문턱의 대수적 가능성은 충분한 검정력이나 실제 정책의 도달을 보장하지 않는다.

**판정 원칙.** D≥0.10%p/G≥0.001, 각 조건부 구간 하한>0, 모든 부모 제외 D/G>0, 미래별 G>0, 기술 무결성 조건을 그대로 둔다. 작은 양의 조건부 근거가 있어도 관측 크기나 견고성 조건 미달이면 **양의 근거/투자 보류**를 함께 기록한다. 미실행·불확실·음의 근거·기술 실패를 구분한다. 모든 부모 제외 값이 양수라는 조건은 한 부모에 대한 전적 의존을 점검하며 넓은 재현을 증명하지 않는다.

**불확실성 범위.** 이번 경계는 고정 예측의 결정론적 산술로 신뢰구간이 아니다. 확인 사례 bootstrap은 예측을 고정하고 짝지은 사례를 재표집한다. 관측된 학습 정책에 조건부이며 미래 분산을 포함하지 않는다. 부모 5개의 기술 구간도 새 부모의 직접 확인을 대신하지 않는다.

**Provenance·seeds.** 부모 41011–41015, prefix 4201/4202다. F1/F2 참조 roots는 [보존한 52번 상태 manifest](inputs/state_manifest.json), 새 F3/F4 제안 roots는 [보존한 57번 작업표](inputs/proposed_jobs.csv)에 있다. seed 수식의 57은 문서 번호 58로 바꾸지 않았다. 원자료는 54번의 paired CSV이며 [입력 provenance](inputs/provenance.json)에 경로·SHA256을 기록했다. 주요 hash는 [보고서 8절](report_ko.md)에 실었다.

**검사·실제 비용.** 수정 생성 29검사, 고정 예측 점검 20,041검사, 별도 유리수 min–max 검산 13,591검사를 통과했다. 새 환경·학습·평가·SAC 업데이트는 0이다. 점검 wall 0.103초·CPU 0.046875초, 검산 wall 0.147초·CPU 0.046875초였고 각 runtime.json에 정확한 값·Python·OS를 남겼다. Python 표준 라이브러리만 사용했다. 실행 소스·입력 snapshot과 실패 기록 규약을 유지했다. 실패한 계산 실행은 없다. 검사 수는 효과의 근거가 아니다.

**다음 판단.** 통계 명세와 고정 예측 점검 범위는 완료했다. 실제 확인에는 독립 실행 구현의 복원·RNG 검증과 20개 미래 결과가 필요하다. 비용 제안은 기술 포함 4.65M, 새 부모 본 비용 2.472M/부모를 유지한다. 이번 문서 기록은 실행 승인이 아니다. 첫 묶음이 투자 기준을 충족할 때만 유한한 새 부모 수·예산·경계 조건을 정하며, 작거나 불확실한 결과로 자동 확대하지 않는다. 최신 완료 과학적 결과는 56번이고 45·54의 기존 관문 판정은 보존한다.
