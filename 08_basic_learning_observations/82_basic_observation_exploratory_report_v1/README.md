# 81번 기본 관측의 파일 전용 탐색 보고서

81번의 고정된 학습·평가 원자료만 읽는다. 학습·환경 reset/step·모델 로드·정책
forward·선택기/예측기 학습은 하지 않는다. 새로운 독립 실험으로 세지 않는다.
81번의 동결 소스가 이 새 버전을 import하거나 변경되지 않도록 별도로 실행한다.

모든 실행·과제·시점과 반대·무변화 사례를 보존한다. 관측된 획득/상실/회복,
에피소드 내 성공 상태 이탈, uniform replay의 실제 표집 기회 대비 사용량을
분리한다. 원시 trajectory와 episode 라벨의 일치 및 정수 성공 집계를 검산한다.
사후 최대값이나 결과로 선택한 사례에는 탐색적 선택 규칙을 표시한다.

wait_and_report.py --campaign 경로는 81번의 종료 후 분석을 자동 수행한다.
신규 환경 예산을 예약하거나 학습 실행을 추가하지 않는다. LATEST.json은 실제
관측 보고서의 경로이며 합성 fixture는 여기에 게시하지 않는다.

초기 합성 보고서 검증에서 생성된 LATEST 포인터가 fixture를 가리킨 문제가
확인되어, 해당 포인터를 verification에 원문 보존하고 기다림 상태로 정정했다.
그 합성 결과는 실제 과학적 증거가 아니며 신규 환경 비용은 0이다.
