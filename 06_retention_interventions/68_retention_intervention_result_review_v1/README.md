대조한다. 원본 구현·결과·검산은 변경하지 않는다. 새 학습·정책 평가·예약은 없다.

`review_results.py`는 정확한 분석/독립 검산의 완료 지문을 확인하고, 기존 집계의
산술·집중도·실제 비용을 재계산한다. 실행마다 고유 results 디렉터리와 입력/소스
해시를 보존한다. 원래20,000회 bootstrap을 재적합하거나 새 통계 기준을 만들지 않는다.

가장 강한 근거는 D(성공 경험 보존)가 C(일반 경험 보존)보다 유리했다는 것이다.

분리한다. 부모·과제·미래에 따른 불리한 결과와 발전 범위를 함께 기록한다.

결과 보고서는 각 실행의 `report_ko.md`, 구조화된 근거 원장은
`evidence_record.json`, 출처는 `input_receipt.json`에 저장된다.
