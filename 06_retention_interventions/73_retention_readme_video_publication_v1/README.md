# 최상위 README의 C/D 설명·영상 공개

2026-10-29 사용자 요청으로 일반 경험 보호 C와 성공 episode 경험 우선 보호 D를
설명하는 영상8개(BP/DC 각각 양방향 결과2쌍)와 GIF 미리보기를 공개한다.
기존71/72와 체크포인트는 변경하지 않고 기존 저장 영상을 복사·인코딩한다.

MP4는 저장 상태 기반 보조 시각화의 바이트 동일 사본이다. GIF는8fps의 압축 미리보기이며
성공 또는500step 종료 뒤의 화면은 관찰 종료로 표시한다. 새 미래나 새로운 행동을 생성하지 않는다.
결과를 알고 고른 설명용 사례이므로 전체 효과의 대표 표본으로 해석하지 않는다.

이번 게시 범위는73의 선택 미디어·출처와 최상위 README의 해당 설명이다.
69/71/72 전체 데이터 및 별도의 로컬 변경은 게시하지 않는다. 로컬 README의 미게시
내용은 보존하고, Git index에는 기존 공개 README에 이번 설명만 더한 내용을 넣는다.

GitHub의 [파일 첨부 규격](https://docs.github.com/en/get-started/writing-on-github/working-with-advanced-formatting/attaching-files)은
GIF와 MP4를 지원하며 영상은H.264를 권한다. 본 README는 GIF 미리보기와 별도MP4 링크를 사용한다.
배포 사이트나 이슈 댓글을 추가로 만들지 않는다.
