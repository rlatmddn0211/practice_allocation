# F05 critic 진단과 최종 성공률 예측

**이번 1차 검증에서는 두 critic 지표의 추가 배분 가치를 확보하지 못했다.**
정규화된 TD 잔차와 critic 간 추정 차이는 별도 replay 표본에서도 대체로 순위가 유지됐지만,
기존 성공률·단기 개선량·규모 정보를 사용한 예측기에 더해도 배분 선택이 좋아지지 않았다.
현재 두 지표를 핵심 예측 요인으로 채택하는 것은 보류한다.

2026-10-14에 기존 E1·E3의 모델과 평가를 재분석했다. 새 학습·환경 평가·learner update는 0이다.
이번에는 F05 중 **critic의 자기일관성과 두 추정값의 차이**를 검증했다.
보상과 성공률의 정합성 전체나 실제 가치 오차를 검증한 것으로 해석하지 않는다.

## 질문과 비교

단기 성공률이 같아도 critic 진단이 다른 상태는 남은 학습에서의 개선이 다를 수 있다는
가설을 살폈다. 높은 TD 잔차가 학습 가능성을 뜻한다고 방향을 미리 단정하지 않았다.
진단값이 현재 성능·보상 규모를 넘어 최종 성능과 배분 선택에 정보를 더하는지가 기준이다.

주 비교는 아래 두 예측기다. 입력 정의와 모델은 결과 집계 전에 [규약](protocol.json)에 고정했다.

| 예측기 | 입력 |
| --- | --- |
| 기준 예측기 Base_scale | 부모의 집중/나머지 과제 성공률, 0→20k의 집중/나머지 성공률 변화, 집중 여부·부모 시점, 보상·soft target 규모 |
| F05 추가 | 위 입력 + 과제별 정규화 TD 잔차의 요약 + 정규화 critic 차이의 요약 |

Uniform, 초기 실패율 선택, 다른 원래 seed에서 정한 고정 배분,
20k 성공률이 가장 높은 배분을 고르는 Greedy20도 비교했다.
F05의 추가 가치는 기준 예측기와의 차이로 판정한다.

## 실제 자료와 측정

| 항목 | 범위 |
| --- | --- |
| 출발 상태 | A 200k·400k, B 200k, C 200k × 원래 seed 11·12·13 = 12개 |
| 사전학습 이력 | 9개; A의 두 checkpoint는 같은 정책 이력 |
| 모델 | 부모 12개 + 각 상태의 5배분 × 3후속 seed의 20k 모델 180개 = 192개 |
| 후속 seed | A: 2101·2102·2103; B/C: 2301·2302·2303 |
| replay 표본 | 모델·과제당 측정 M 1,024개 + 확인 A 1,024개, 총 1,572,864 transition |
| target action 표본 | transition마다 현재 정책의 다음 행동 4개 |
| 이후 성능 | 기존 148,800 평가 episode 행, 20k·40k 및 부모 성능 |

500-step episode 경계와 task one-hot을 검증했다. 과제별 episode를 시간순으로 짝지어
한쪽은 M, 다른 쪽은 A에 배정하고, 각 panel 안에서 여덟 시간 구간을 같은 수로 표집했다.
두 panel은 같은 episode를 공유하지 않는다. 그러나 둘 다 모델이 이미 학습에 사용한 replay이며,
학습 과정 전체에서 독립된 새 검증 자료는 아니다.

진단용 soft target은 다음과 같다.

```text
y = reward + gamma × [1 − done × (1 − timeout)]
             × mean_4_actions[min(Q1_target, Q2_target) − alpha × log pi]
```

저장된 행동에서 두 critic의 `(Q−y)` 제곱을 평균한 뒤 제곱근을 취해 TD 잔차를 구했다.
critic 차이는 `(Q1−Q2)`의 RMS다. 각 값을 해당 task의 target RMS로 나누고,
`log1p`를 적용한 네 과제 평균 두 개를 F05 입력으로 사용했다.
SAC의 entropy 항과 timeout bootstrap을 유지했으며, 보상·target 규모도 별도 기준 입력에 넣었다.
한 행동 표본의 학습 TD 통계와 달리 이번 잔차는 네 다음 행동의 평균 target에 대한 진단이다.

**작은 잔차는 실제 가치가 정확하다는 보증이 아니다.** target critic도 같은 학습 과정에서
만들어졌고, 두 critic이 함께 틀릴 수 있다. Monte Carlo soft value의 정답과 비교하지 않았다.
원본 파일 hash와 복원된 학습·replay hash를 확인하고 진단 전후 상태가 같은지 검증했다.

## 예측과 채점의 분리

이전 F07과 같은 hash 규칙으로 기존 과제당 100사례를 선택용 D 50개와 채점용 O 50개로 나눴다.
기존 연구에서 이미 본 자료이므로 이 분리는 새로운 독립 확인을 만들지 않는다.

원래 seed 하나를 검증할 때 모든 구성·부모 시점의 해당 seed를 학습에서 제외했다.
남은 두 seed에서 표준화와 회귀를 적합하고, 20k D 성능 및 그때의 진단으로
같은 실제 분기의 40k D까지 남은 변화를 예측했다. 이후 검증 seed에서 선택된 분기의
40k 성능은 O로 계산했다. 데이터가 적어 ridge penalty 1을 고정했고, 결과에 맞춰 조정하지 않았다.

주 분석은 각 출발 상태·후속 seed에서 다섯 배분 중 하나를 고른다. 따라서 선택은 36건이다.
보조 분석은 다른 두 후속 seed의 20k 예측을 평균해 고르고, 남긴 후속 seed의 40k를 채점한다.
서로 다른 분기의 상태를 이어 붙이지 않는다. A/B/C에 같은 가중치를 주고,
A 안에서 200k·400k를 같은 가중치로 평균했다.

## 불확실성과 판정 범위

원래 seed 블록이 세 개뿐이며 모든 자료는 이전에 본 개발 자료다.
새 seed에서의 효과나 모집단 유의성을 주장하지 않는다. 채점 사례만 재표집한 구간은
학습 결과·회귀·진단 사례·선택을 고정한 조건부 구간이다.
주 F05와 기준의 사례 구간이 [0, 0]인 것은 두 방법이 정확히 같은 정책을 골랐기 때문이다.
다른 상태에서도 진정한 효과가 0이라는 증거가 아니다.
[조건부 사례 구간](results/20261014T062648Z_analysis_4a05b167/conditional_case_intervals.csv)

v23의 탐색 선별 기준은 평균 추가 선택 이득 +1%p, 세 원래 seed 중 두 개 이상에서 양수,
구성별 큰 악화 점검이었다. 주 비교는 이 기준을 통과하지 못했다.
이 운영 기준을 통계적 유의성이나 후보 전체의 반증으로 해석하지 않는다.

**현재 판정: 이번 두 critic 지표의 핵심 요인 채택 보류. F05 전체는 부분 검증 상태.**
다음 항목은 여전히 구분해서 남긴다.

- 같은 정책·초기 상태·500-step 길이에서 return과 성공률의 관계를 측정하는 부분.
- 실제 soft value 오차의 검증. 현재 replay 잔차·critic 일치도는 이를 대신하지 못한다.
- 4k의 작은 진단에서 같은 정보가 유용한지와 새 원래 seed에서의 확인.
- 진단 비용을 포함한 같은 총예산의 실제 배분 비교.

학습 episode의 return은 학습 도중의 확률적 정책으로 얻었고, 기존 평가는 deterministic
정책이 성공하면 종료한다. 이 값을 직접 섞어 보상·성공 정합성을 검증했다고 하지 않았다.

실행별 시간은 문서 작성 시간과 다르고, 병렬 실행의 시간을 더한 값은 실제 경과시간과 다르다.
예비 실행과 실패한 검증의 비용도 각 실행 summary에 남겼다.
Python 3.12.0, PyTorch 2.5.1+cu121, SB3 2.7.1, NumPy 2.2.4, SciPy 1.17.1을 사용했다.

이번 재분석의 환경 비용 0과 실제 온라인 적용 비용은 다르다. 주 선택은 다섯 배분을
각각 20k 학습한 정보를 사용하므로 사전 진단 학습만 100k다. 선택용 D 평가도 평균
309,082 step이다. 별도 후속 반복으로 예측하는 보조 분석은 200k 학습·618,164 평가 step이다.
부모 성능과 개발 고정 배분의 과거 준비 비용도 따로 존재한다.
따라서 위 표는 진단 포함 총예산 40k에서의 온라인 배분 효과가 아니다.

## 기술 검증과 보존된 실패

본 측정의 12,674개 검사에서 checkpoint·패키지·task·episode·학습/replay 복원과 비변경을 확인했다.
독립 NumPy 검증은 1,572,864개 transition의 target·잔차·critic 차이를 다시 계산했고
24,195개 검사를 통과했다. 별도 구현은 원시 성공 기록에서 입력을 다시 계산하고,
증강 최소제곱으로 ridge 15개를 재적합해 예측 900개와 선택 648개를 확인했다.
