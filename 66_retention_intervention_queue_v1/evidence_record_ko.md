# 첫 보존 개입의 실행 상태와 과학적 결론

2026-10-27. 이전 설계63 및 기준선64와 연결하는 독립 실행 버전.

- **승인:** 사용자가40분기·BP625·새 미래2개·분기32k·총10.10M/기술20k와
  기준선 종료 후 Windows 백그라운드 자동 실행을 명시 승인했다.
- **실행 상태:** 예약 시에는 대기 중이다. 실제 상태는 ACTIVE_QUEUE.json이
  가리키는 STATUS.json 및 이후 ACTIVE_CAMPAIGN.json을 확인한다.
- **과학적 결론:** 미측정. 보존 효과, 성공 경험 선택 효과, 획득·회복 보장의
  어느 것도 예약/정적 검사/기술 검사만으로 확인됐다고 주장하지 않는다.
- **출처:** 부모41011–41015, 각 prefix4201의 기존208k 전체 상태.
  input manifest에 체크포인트/은행/과거 라벨 해시, jobs에 새 실제 seeds를 고정.
- **비용:** 대기·정적 검사0환경 step. 이후 모든 기술/실패 시도와 연구 비용은
  개별 costs.json에 기록해 누적 상한에 포함한다. 기존 사전학습은 재사용 자산.
- **주 비교:** 같은 조건·teacher·loss·계수·task/age/episode/배치 규칙의 D−C.
  J/G/L/R과 B−A/C−A/D−A도 보고하며 R은 G에 포함된다.
- **불확실성:** 독립 부모5개, 부모당 새 미래2개. 사례 조건부 구간은 관측한
  정책의 평가 사례 변동이며 새로운 학습 미래/부모 분산 전체가 아니다.
- **한계:** 이미 여러 번 본 과제/부모/O100에서의 개발 실험. 역사적 성공은
  현 teacher의 숙달 증거가 아니며, 같은 KL계수는 같은 실제 보호 강도가 아니다.
  희소/없는 성공 지원, fallback과 각 과제 기여를 감추지 않는다.
- **다음 판단:** 모든40개 상태와 획득·상실·회복 및 최종 점수를 보고한다.
  불리하거나 불확실한 결과도 유지하고 자동 확대하지 않는다. 새 부모·더 긴
  예산·MT10·원인 개입은 별도 후속 결정으로 남긴다.

구체 수식·메모리·예산·seed·평가는 protocol.json 및 README.md에 고정한다.
보존 방법 구현과 큐의 검증 산출물은 새로운 results 하위 디렉터리에 보존한다.
