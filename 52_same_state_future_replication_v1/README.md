# 동일 8k 상태의 BP 미래 반복 실행

2026-10-20 사용자가 51번 계획의 실행을 승인했다. 이 버전은 별도의 실행 구현이다.
[과학적 명세 51](../51_same_state_future_investment_protocol_v1/research_protocol_ko.md)와
기존 선택표를 보존하고, 새 결과를 본 뒤 선택·평가 기준을 바꾸지 않는다.

| 항목 | 범위 |
| --- | --- |
| 부모 | 41011–41015, 5개 |
| 기존 8k 상태 | 부모당 prefix 4201/4202, 총 10개 |
| 새 미래 | 상태당 1개, 기존 미래 포함 상태당 총 2개 |
| 추가 학습 | 기존 BP dose625 유지 32k × 10 = 320k |
| 평가 | 새 최종 정책마다 같은 O100 × 4과제, 최대 2M |
| 본 실험 환경 step 상한 | 2.32M |
| 기술 검증 전체 시도 상한 | 10k; 첫 검증 계획은 최대 5k |
| 전체 상한 | 2.33M |
| 실행 | 단일 worker로 10개 학습·평가를 순차 실행 |

학습된 모델·optimizer·entropy·replay·collector·일정 위치는 유지하고 이후 난수만 바꾼다.
기존 `start_branch`는 호출하지 않는다. 학습·환경·평가 함수는 44번에서 그대로 복사했다.
full checkpoint는 절대 216k/224k/232k/240k에 무손실 저장하며 중간 정책 평가는 없다.
평가는 성공 시 조기 종료하므로 2M은 실제 사용량이 아니라 상한이다.

기술 관문은 열 상태의 전체 복원, RNG 변경 전후 비난수 상태 동일성,
동일 RNG의 짧은 학습 재현, 새 RNG에서 연속 실행 대 저장·재개 동일성,
기존 8k 정책의 평가 사례 재현이다. 통과는 과학적 효과의 증거가 아니다.
원본 checkpoint와 이전 결과는 덮어쓰지 않는다. 모든 실행은 새 디렉터리와 소스 snapshot/hash를 남긴다.

실행 기록은 `results/*_technical_*`, `ACTIVE_CAMPAIGN.json`이 가리키는 campaign,
그 안의 `STATUS.json`, `jobs/*/*/progress.jsonl`, `costs.json`에 저장된다.
검증 실패나 실험 무결성 실패 시 중단하고 자동 재시도하지 않는다.
작업 재시작 시 미완료 시도를 자동으로 중복 실행하지 않는다.
시스템 재부팅 뒤 무조건 재실행하는 작업 스케줄러 등록은 하지 않는다.

분석 기준은 복사된 `inputs/protocol51.json`의 두 교차 반쪽 주분석과 두 고정 행동 비교,
부모 단위 집계·제거·집중도 및 조건부 사례 구간을 그대로 따른다.
기존 완성 미래로 만든 선택표이므로 실제 8k 선택 알고리즘의 검증으로 해석하지 않는다.
C·원래 2/3단계·replay 개입·새 임계값 탐색은 이 실행 범위에 포함되지 않는다.

`evidence_record_ko.md`는 실행 전 범위 기록이다. 실행 완료 여부는 기계 기록으로 구분하며,
새 과학적 결론은 전체 결과를 분석한 독립 후속 기록에 남긴다.
