# 피드백 항목별 적합성 판단과 반영

2026-10-19. 평가 대상은 41번 설계와 42번 구현이다. 사용자가 제공한 피드백 자체를 검토 근거로 삼으며 새 문헌 검토를 수행했다고 주장하지 않는다. 과학적 결과를 보고 수정한 것이 아니다.

| 부모 제외 시 기준 선정까지 재계산 | 채택·분석 변경 | 기존 구현은 이미 계산한 이득에서 하나만 제거했다. 이제 제외한 부모가 다른 부모의 기준 선정에 기여하지 못하도록 전체 교차 선택을 다시 계산한다. 기존 삭제 방식은 보조 민감도로만 남긴다. |

| 블록 중간 종료와 실제 과제량 | 채택·명시 | 원래 순서를 그대로 자르고 종료한다. quota 재배분·셔플·phase/RNG 초기화를 하지 않는다. 실제 과제별 수집량을 기록한다. |

| 3단계 진단 후 항상 전환 | 필수 채택 | 적응형이 모든 상태에서 전환하는 경우 정보의 추가 가치는 0이다. 항상 유지 대비 이득만으로 정보 기여를 주장할 수 없었다. |
| 진단 없는 F*8k→A*32k | 필수 채택 | 고정 전환 자체가 좋은 경우를 강한 고정 기준에 포함한다. 새 부모 결과를 보고 약한 고정 기준만 고르지 않는다. |
| 공통 경로·36/40k 정책 공유 | 조건부 채택 | 진단 상태 불변, 종료 길이에 독립적인 학습, 미래를 보기 전 행동 기록을 기술적으로 확인해야 한다. 조건 충족 시 실제 학습72k+진단4k/부모·반복, 각 방법의 운영 비용은 각각40k다. |
| 점수·방향·임계값·적합·동점 | 채택·구체화 | BP 성공률−나머지 평균이라는 점수 하나를 고정한다. 가능한 13개 값 사이의 12개 경계×2방향+두 상수 행동=26개 유한 후보다. 결과에 따라 점수 정의를 바꾸지 않는다. |
| 2단계 부모 제외 평가의 조건부 성격 | 채택·명시 | F*/A* 선택에 모든 1단계 부모가 참여했다. 새 O100과 LOPO가 일정 선택까지 독립화하지 않는다. 별도 중첩 학습을 추가하지 않는다. |
| 10개 8k 상태의 반복 단위 | 채택·명시 | 각 부모의 서로 다른 8k 상태 두 개에 미래 한 쌍씩이다. 동일한 한 상태의 기대 전환 이득을 여러 미래 seed로 반복한 것이 아니다. |
| 평균 1·2위 쌍의 한계 | 유지·명시 | 평균 1위 F*, 2위 A*라는 단순 규칙은 유지한다. 1단계에서 우열이 교차한 쌍과 다를 수 있고, 2단계 음성 결과는 우선 이 쌍·이 진단 규칙에 제한된다. |
| 엄격한 탐색 진행 기준 | 유지 | 유의성 검정이나 가치 부재의 증명으로 해석하지 않는다. 1단계 미통과가 8k 전환 가치 부재를 뜻하지 않는다. |

기존 설계의 핵심 결함은 3단계에서 **항상 유지 대비 정보 기여**만 검사했던 점이다. 이 문서는 그 비교를 두 상수 행동 대비 비교로 바꾸고, 진단 없는 두 고정 일정까지 사전 비교 대상으로 둔다. 단순한 표현 보완과 실제 분석/실행 변경을 위 표에서 구분했다.

2단계의 단일 점수는 유효성이 확인된 요인이 아니다. 26개 후보의 적합도 개발 자료에서 이루어지므로 조건부 LOPO 이득조차 최종 확인으로 부르지 않는다. 3단계의 새 부모 검증이 필요하다.
