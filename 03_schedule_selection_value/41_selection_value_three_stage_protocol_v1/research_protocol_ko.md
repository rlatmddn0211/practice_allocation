# 세 단계로 분리한 연구 목표와 판정

2026-10-19. 39번의 미실행 제안을 보존하고 이 문서로 후속 방향을 갱신한다. 이번 사용자 지시는 1단계부터 순서대로 진행하는 승인이다. 완료한 E0–E3와 후보 기록을 수정하지 않는다. 이후 단계의 실행은 아래 과학적 조건과 기술 검증을 충족해야 한다.

## 무엇을 바꾸는가

39번의 첫 패킷은 교대−혼합 재현을 주 대조로 두었다. 이제 **강한 고정 방법을 넘어서는 반복 가능한 선택 여지**가 첫 과학적 목표다. 교대−혼합 평균 +2%p나 교대의 평균 우위를 전체 연구의 필수 진행 조건으로 사용하지 않는다. 모든 부모에서 교대가 좋으면 더 좋은 고정 일정의 발견이며, 상태별 선택의 근거와 구분한다.

세 질문은 별도 실험으로 답한다.

| 단계 | 직접 답할 질문 | 답할 수 없는 주장 |
| --- | --- | --- |
| 1 | 출발 상태에 따라 좋은 고정 일정이 달라지고, 그 우열이 후속 반복에서 유지되는가? | 8k에서 바꾸면 좋아진다, 저렴한 신호로 알 수 있다 |
| 2 | 같은 8k 상태에서 유지·전환의 실제 결과가 달라지는가? 당시 정보로 그 선택을 식별하는가? | 진단 때문에 줄어든 학습량을 감수해도 이득이다 |
| 3 | 새 부모에서 진단 비용을 지불한 선택이 동일 총예산의 강한 고정 방법을 이기는가? | 다른 task 구성·benchmark 전반의 일반 법칙 |

## 공통 원칙

주 목적은 네 과제의 동일 가중 최종 성공률이다. 과제별 손익·최악 과제 손실·부모 대비 변화도 공개한다. 보상, deterministic 평가, 500-step 학습 종료 규칙, replay, SAC를 동시에 바꾸지 않는다. B 구성의 기존 dense reward, 공유 SAC와 학습 설정을 유지한다.

원래 seed가 주 독립 단위다. 후속 반복과 평가 사례를 새 부모로 세지 않는다. 효과의 평균뿐 아니라 부모별 두 반복, 구간, leave-one-parent-out 민감도를 제시한다. 다섯 부모는 탐색 규모이며 충분한 검정력이나 음성 결과의 등가성을 보장하지 않는다.

단계 전체의 사전 명세 셀은 유불리와 무관하게 완료한다. 성능으로 부모를 선별·교체하거나 예산을 연장하지 않는다. 기술 무결성 실패는 중지하고 실패 시도·실제 비용을 보존한다. 상태·checkpoint·최종 점수·진단 입력의 출처를 연결한다.

## 1단계: 고정 방법과 부모별 선택 여지

새 부모 seed 41011–41015를 각각 Uniform 200k 사전학습한다. 후속 라벨 4201/4202의 실제 RNG seed는 부모와 라벨에서 결정적으로 파생한다. 각 부모/후속 seed 안에서는 조건 간 RNG 시작점을 짝지으며, 새 부모를 기존 11/12/13/901과 혼동하지 않는다.

| 조건 | 명세 | 해석 |
| --- | --- | --- |
| BP 고정 (`dose625`) | 8k마다 BP 10 episode, 나머지 각 2 episode, 블록 안 셔플 | 개발 자료에서 미리 정한 강한 고정 기준 |
| 교대 (`alternate4k`) | BP 집중 4k → DO 집중 4k, 다섯 쌍 | 일정 자체는 고정; 적응형 선택 아님 |
| 혼합 (`mixture`) | 4k마다 BP/DO 각 3 episode, DC/PU 각 1 episode | 교대와 총 과제 수집량이 같은 대조 |

기존 F08의 블록 길이·순서 규약을 복사해 유지한다. 교대와 혼합은 각각 BP/DO 15k, DC/PU 5k다. BP 고정은 BP 25k, 나머지 각 5k다. 총량이 다른 BP 비교는 실제 방법 비교이며 순수 시간 배치 인과 대조로 부르지 않는다.

5 × 2 × 3 = **30분기**, 각 +40k다. 사전학습 1.0M + 분기 1.2M = **2.2M 학습 step**. 부모 5개와 최종 정책 30개를 과제별 100사례로 평가하므로 14,000 episode, 최대 7.0M 평가 step, 합계 **9.2M 환경 step 상한**이다. 기술 검사·중단 재시도 비용은 따로 더한다. 초기 환경 생성/reset 비용과 저장·CPU·wall time도 별도 기록한다.

사전학습은 20k마다, 분기는 4k/8k/20k/40k에서 전체 learner·optimizer·replay·collector·RNG를 무손실 저장한다. 1단계에서 중간 정책 평가를 하지 않는다. 과거 bank 및 학습 reset과 겹치지 않는 새 평가 bank를 만들고 실제 학습 reset과도 대조한다. 부모 평가 점수는 부모 선택·학습 중단에 사용하지 않는다.

### 분석과 진행 조건

1. BP 대비 교대·혼합의 부모별 차이를 우선 보고한다. 교대−혼합은 별도의 일정 대조다.
2. 최종 O100은 미리 사례 인덱스 0–49/50–99로 반분한다. 한 후속 반복의 한 반쪽으로 부모별 방법을 고르고, 다른 후속 반복의 다른 반쪽에서 채점한다. 두 반복 방향과 두 반쪽 방향을 모두 계산한 뒤 부모별로 평균한다. 이것은 **비싼 최종 정보로 만든 탐색용 선택 가능성 평가**이며 실제 온라인 방법이나 이론적 상한이 아니다.
3. 기준은 사전 고정 BP와, 해당 부모 전체를 제외한 다른 부모의 선택 반쪽 자료로 고른 고정 방법이다. 동점 우선순위는 BP → 교대 → 혼합이다. 전체 자료의 최고 평균 고정 방법도 기술통계로 보고하되, 이 방법의 사후 선택을 독립 검증이라고 부르지 않는다.
4. 다음 단계 투자 조건은 (a) 동일 방법 쌍에 대해 두 후속 반복 모두 최소 2%p 차이를 보이는 반대 방향의 부모가 각각 하나 이상, (b) 교차 반복·교차 사례 선택 이득이 BP 및 부모 제외 고정 방법보다 양수, (c) 부모 하나씩 제외해도 두 이득의 평균이 양수다. 이는 **탐색 운영 기준**이며 통계적 유의성이나 선택 가치 부재의 증명이 아니다. 조건 미충족은 `inconclusive_or_fixed_sufficient_in_tested_scope`로 남긴다.
5. 부모 유지 행동을 추가한 선택은 별도 보조 분석이다. 이것만 이기면 전환 연구 통과로 바꾸지 않고, 추가 학습 중단을 다룰 명세가 필요한 것으로 기록한다.

한 고정 방법이 일관되게 좋으면 이를 다음 고정 기준으로 채택하고 적응형 확장을 자동 진행하지 않는다. 교대−혼합 차이가 작아도 위 선택 조건을 충족하면 2단계로 갈 수 있다. 불확실하면 해당 범위에서 미확인으로 기록하고 희귀 양성 사례만 추적하지 않는다.

이 보류는 연구 자원의 우선순위 판단이다. 시작 시점의 세 고정 일정 사이에 반복 가능한 차이가 없다고 해서 8k 이후 실제 전환 가치까지 없다고 증명한 것은 아니다. 서로 다른 단계의 질문을 음성 결과에서도 혼동하지 않는다.

## 2단계: 같은 8k 상태에서 유지·전환과 신호 식별

1단계의 전체 평균이 가장 높은 고정 방법 F*와 나머지 중 평균이 높은 대안 A*를 동결한다. 여기서 고른 F*는 2단계의 개발 기준이며, 이후 새 부모에서 평가한다. 1단계 자료는 이 선택에 쓰였으므로 확증 자료로 다시 부르지 않는다.

각 부모×후속 반복의 **F* 8k 전체 checkpoint** 열 개를 사용한다. 같은 상태에서 F* 유지와 A* 전환을 실제 실행한다. F*의 기존 8k→40k suffix는 상태 hash·RNG·정확한 목표 시점 일치가 검증되면 재사용할 수 있다. A*는 8k에서 실제 32k를 새로 학습한다. 다른 시작 일정의 40k 결과를 이어 붙이지 않는다.

전환은 수집 일정만 바꾼다. actor/critic/entropy/optimizer/replay, reset 방문 횟수, 현재 RNG를 그대로 유지한다. 전환 때 `start_branch()`로 모든 후속 stream을 재설정하지 않는다. 교대로 전환하면 전환 직후를 BP phase 시작으로 고정하고, 남은 32k의 양 끝 phase도 명시한다. 1단계에서 선택한 대안의 스케줄 블록 규약은 유지한다.

8k 정책의 진단은 새 D bank의 **과제별 2사례, 각 고정 500-step**, 총 4k다. 성공 후에도 끝까지 평가하여 실제 진단 비용을 정확하게 4k로 만든다. 성공 여부는 500-step 안의 any-success이며, 진단 자료는 replay에 넣지 않고 원래 학습 상태/RNG를 변경하지 않는다. 사전 부모 평가나 대안 미래 점수를 무료 입력으로 제공하지 않는다.

새 학습은 10 × 32k = 320k, 진단 40k다. 유지·전환 20개 정책을 새 공통 O100으로 평가하면 최대 4.0M, 합계 **4.36M 환경 step 상한**이다. 기존 suffix 재사용 불가 시 추가 유지 학습 320k는 명시적 변경 사항으로 기록하며 몰래 추가하지 않는다.

먼저 실제 전환−유지 차이가 부모별로 반복되는지 확인한다. 이후 규칙은 **결정 시점의 한 점수에 대한 임계값 하나**로 제한한다. 점수의 정의, 방향 후보, 유한 임계값 집합은 2단계 결과를 보기 전에 별도 명세로 동결한다. 가령 8k 진단의 BP 성공률과 다른 과제 평균의 차이를 쓸 수 있지만 현재 이를 검증된 요인으로 채택하지 않는다. 미래 손실·40k 결과·원래 seed 번호를 입력으로 사용하지 않는다.

임계값 적합은 부모 전체를 제외한 교차검증으로 평가한다. 항상 유지와 항상 전환을 모두 기준으로 삼는다. 한 행동이 모든 상태에서 좋으면 고정 전환 일정의 발견이다. 두 고정 행동보다 양의 선택 이득이 남고, 반복·부모 제외 민감도에서 유지되는 경우에만 최종 규칙을 동결하여 3단계로 진행한다. 1단계의 판정만으로 이 조건을 충족했다고 간주하지 않는다.

2단계는 진단 이후에도 32k를 학습하는 개발 실험이므로 44k의 운영 비용에 해당한다. 여기서의 이득은 비용 회수를 입증하지 않는다. 규칙을 고른 데이터에 대한 성능도 최종 확인으로 제시하지 않는다. 특히 32k에서 유리한 전환이 3단계의 28k에서도 유리하다고 가정하지 않는다. 줄어든 잔여 학습 길이에서 선택이 실패하면 그 결과도 비용 포함 실패로 기록한다. 2단계 결과를 보고 28k 보정 자료를 추가할 경우에는 별도 명세와 비용을 먼저 고정하며 기존 결과를 덮어쓰지 않는다.

## 3단계: 새 부모에서 비용 포함 성능

규칙·고정 기준·평가 bank·효과 기준·표본 수를 새로운 결과 전에 동결한다. 부모는 1·2단계에서 쓰지 않은 seed다. 표본 수는 2단계 부모 간 변동과 필요한 정밀도로 정하며, 다섯 부모가 자동으로 확증 규모라고 가정하지 않는다. 이번 구현에 미정 수량의 3단계 학습을 예약하지 않는다.

| 방법 | 학습 | 진단 | 총 운영 환경 예산 |
| --- | ---: | ---: | ---: |
| 강한 고정 F* | 40k | 0 | 40k |
| 진단 기반 선택 | 공통 F* 8k + 선택한 유지/전환 28k | 4k | 40k |
| 정보 무시 대조 | 공통 F* 8k + F* 유지 28k | 같은 4k | 40k |

정보 무시 대조는 같은 진단을 실제 실행하고 선택에는 쓰지 않는다. 세 방법은 같은 부모와 짝지은 후속 stream에서 시작한다. 동일 prefix나 진단 결과를 물리적으로 공유하면 절약된 실제 연구 비용과 각 방법이 부담하는 운영 비용을 모두 기록한다. 진단 없는 기준에 미래 정보를 제공하지 않는다.

주 비교는 선택 방법−강한 고정 방법, 정보 기여는 선택 방법−정보 무시, 진단 기회비용은 정보 무시−강한 고정이다. 각 정책을 실제 길이로 학습하며 40k 성적의 보간으로 36k/전환 결과를 만들지 않는다. 최종 연구용 O 평가는 방법에 피드백하지 않고 운영 40k와 분리하여 공개한다.

새 부모 평균에서 사전 명시한 실용적 순이득과 불확실성 기준을 충족하고 정보 기여도 양수여야 비용 포함 개선으로 판정한다. 정보 기여만 양수면 신호의 예측 가치는 있을 수 있지만 비용 회수에는 실패한 것이다. 세 결과와 부모별 손실을 모두 보존한다.

## 기록·범위

실행 완료, 과학적 진행 기준 통과, 온라인 개선 확인을 별도 필드로 기록한다. seed·설정·dependency·source/input hash·실제 학습/진단/평가 비용·실패 시도·불리한 결과를 남긴다. 단계 완료 기록은 새 번호 폴더로 25/37/38번 근거 기록과 연결하고 root index를 갱신한다.

이 연구의 첫 범위는 B 구성, 공유 SAC, dense reward, 200k 부모와 40k 추가 예산이다. B에서의 선택·전환 가치를 다른 benchmark의 일반 원리로 확대하지 않는다. 중단 정책·원인 메커니즘·새 benchmark는 현재 세 질문과 구분한다.
