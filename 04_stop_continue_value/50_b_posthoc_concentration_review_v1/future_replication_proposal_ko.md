# 선택 사항 — 같은 BP 8k 학습 상태에서 미래 반복

2026-10-20 사용자 피드백을 반영한 **미실행·미예약 제안**이다.
현재 후보 확대를 다시 시작하는 승인이나 C·원래 2·3단계 재개가 아니다.
기술 실행 명세와 판정 기준까지 동결한 실행 준비 완료 문서도 아니다.

## 목적

`g(s8) = E_future[J40(s8, future)] − J8(s8)`

현재 학습 상태를 고정했을 때 지속의 평균적인 순가치가 어떤 방향인지 조사한다.
B는 각 상태에서 미래 한 번의 실현값을 관측했다.
이 제안은 같은 상태의 미래를 한 번 더 얻어 기존 손익이 반복되는지 탐색한다.
좋은 사전 지표를 확보하기 전에도 가능한 **반응의 반복성 측정**이다.
예측기·중단 알고리즘·전환 알고리즘의 검증을 대신하지 않는다.

`s8`에는 학습된 actor/critic·target·entropy 계수·optimizer·replay·시간 카운터·수집 상태·일정 위치를 포함한다.
이후 사용할 난수 stream은 조작 대상이므로 보존 대상인 비난수 상태와 명확히 분리해 명세해야 한다.
계산 상태의 난수 값까지 모두 그대로 고정하면 같은 미래를 다시 실행하는 것과 구분되지 않는다.

## 제안 규모

| 항목 | 범위 |
| --- | --- |
| 부모 | 41011–41015 |
| 8k 상태 | 각 부모의 4201·4202 경로, 총 10개 전부 |
| 행동 | 원래 BP 집중 일정의 지속 한 가지 |
| 새 미래 | 상태당 1개, 총 10개 |
| 상태당 새 학습 | 32k, 절대 208k→240k |
| 새 학습 합계 | **320,000 step** |
| 최종 평가 | 새 40k 정책 10개 × 같은 O100 4과제 |
| 최종 평가 상한 | **2,000,000 step** |
| 본 실행 환경 상한 | **2,320,000 step** |
| 중단 대조 | 이미 평가한 같은 J8 재사용; 중단 학습 분기 없음 |
| 기술 검사·실패·재시도 | 본 실행과 별도. 아직 예산·중단 규약 미동결 |
| 실제 신규 지출 | **0** |

41014/4202·41015만 골라 실행하면 사후 선정 사례 연구가 된다.
현재 상태 집합의 반복성을 다루려면 제시한 열 상태 전체를 유지한다.
기존 미래와 새 미래를 합쳐 상태당 두 미래가 되지만, 독립 부모는 여전히 5개다.
두 미래만으로 상태별 기대값·분산을 정밀하게 추정했다고 주장할 수 없다.

## 실행 전에 해결해야 할 상태 보존 사항

현재 [engine.py의 start_branch](../48_bp8k_checkpoint_evaluation_v1/practice_allocation/engine.py#L60)는
새 분기를 위해 schedule을 다시 만들고 task visit 카운터를 0으로 설정하며
replay의 `branch_start_step`을 변경한다.
이를 그대로 호출하는 방식은 이번 “동일 8k 비난수 상태 보존”의 명세와 맞지 않는다.
현재 함수를 수정하지 않고, 실행을 선택한다면 독립된 새 버전에서 별도 복원·난수 교체 경로를 구현해야 한다.

실행 전 확인할 사항은 다음과 같다.

1. 원본 full checkpoint의 hash·package·전체 복원 fingerprint 확인.
2. actor/critic/target, optimizer moments·counter, entropy 상태, replay 내용·위치·기존 branch 경계,
   task visits·collected steps·num_timesteps, 일정 cursor·이미 정해진 순서를 그대로 유지.
3. global Python/NumPy/Torch CPU·CUDA, reset seed root, future schedule shuffle 등
   실제 사용되는 난수원을 열거하고 바꿀 항목을 정확히 명세. 이후 task visit 번호도 0으로 되돌리지 않음.
4. 수집 상태와 일정의 기존 위치를 확인. 이 구현의 full checkpoint는 episode 경계에 저장되므로
   경계 조건을 검증하고 임의 reset·warm-up 재시작·시간 카운터 초기화를 금지.
5. 바뀐 난수 필드와 그대로인 비난수 필드를 각각 검증.
   최종 결과를 보기 전에 새 미래 seed와 실제 파생 RNG mapping을 고정.
6. 기술 검사의 실제 비용·허용 상한·재시도 규약을 먼저 정하고 실패한 시도도 별도 폴더에 보존.

새 예산을 이유로 학습률 일정·종료 처리·replay 규칙을 바꾸지 않는다.
이번 문서에서는 새로운 seed 번호를 임의로 선택하거나 실행기를 만들지 않았다.

## 분석에서 구분할 것

각 상태에서 기존 미래와 새 미래의 `J40−J8`을 모두 보고하고,
부호·차이 크기·부모별 두 상태·과제별 손익·성공 패턴을 함께 제시한다.
직접적인 `J40_new−J40_old`도 보면 공통 J8을 뺀 값들의 기계적 상관과 미래 결과 차이를 구분하는 데 도움이 된다.

단순한 두 후기 변화량의 상관만으로 상태 효과를 주장하지 않는다.
`g1_hat = J40_old_hat−J8_hat`, `g2_hat = J40_new_hat−J8_hat`는
공유된 J8 측정 오차 때문에, 오차 항만 보아도 양의 공분산을 가질 수 있다.
또 같은 평가 사례에서 세 정책을 평가하므로 이 오차들을 서로 독립이라고 가정할 수도 없다.

그 때문에 실행 전 다음을 동결해야 한다.

- 모든 시점·미래에 동일 인덱스를 적용하는 짝지은 사례 불확실성 및 부모 단위 집계.
- 두 미래 사이의 반복성 지표와, 단순 상관 이외의 차이·부호·효과 크기 보고 방식.
- 필요하다면 서로 겹치지 않는 평가 반쪽에서 두 미래의 대비를 구성하는 보조 분석.
  반쪽 구분·집계는 새 미래 결과를 보기 전에 고정하고 이미 본 O100이라는 한계를 유지.
- 한 부모를 제외할 때 고정 기준까지 다시 계산하는 집중도 분석.
- 실용적인 차이와 재현 범위를 판단할 수치 기준, 불확실할 때의 종료 판단.

후기 차이가 반복되더라도 과거 미래의 최종 성적을 사용한 선택은 실제 8k 의사결정 입력이 아니다.
현재 O100은 연구용 측정이므로 무료 온라인 진단으로 사용할 수 없다.
같은 bank로 하는 이 검사는 새 미래에 대한 제한된 개발 확인이며,
새 부모 전체에 대한 선택 알고리즘 독립 검증으로 부르지 않는다.

## 결과별 판단 방향 — 수치 관문은 아직 미동결

| 결과 | 다음 판단 |
| --- | --- |
| 기존 손익이 새 미래에서 크게 달라짐 | 일회 미래를 예측 목표로 삼은 상태별 선택기 확대 근거 부족 |
| 차이가 작거나 활용 여지가 다시 한 부모에 집중 | 현재 설정에서 선택기 개발 확대를 마무리할 근거. 선택 가치 부재의 증명은 아님 |
| 여러 부모·상태에서 실용적인 양방향 손익이 반복 | 사전 입력·비용·한정된 규칙을 연구할 별도 명세를 검토할 근거 |
| 모두 비슷한 방향 | 상태별 선택보다 좋은 고정 행동을 우선 비교 |

어느 경우에도 새 전환 행동·다른 결정 시점·추가 부모를 자동으로 늘리지 않는다.
차이가 반복되더라도 그 상태를 알아낼 수 있는지, 정보를 얻는 비용을 회수하는지는 별도 질문이다.

## 별도 가능성: 고정 중단으로 학습량 절약

추가 40k 대신 8k는 추가 학습 step 80% 절감, 사전학습 포함 240k 대신 208k는 13.333% 절감이다.
현재는 비열등성·동등성도 확보하지 못했다.
이 방향을 선택한다면 허용 성능 손실, 절약한 step의 가치, 비교할 고정 시점,
새 부모의 확인 기준을 먼저 정해야 한다.
이 제안을 적응형 배분 연구의 사후 성공 판정으로 사용하지 않는다.
