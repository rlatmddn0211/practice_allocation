## 2. 결과를 다 알고 고르는 사후 선택도 한 부모에 크게 의존한다

각 **부모×후속 경로**에서 네 과제 평균의 `J8`과 `J40` 중 큰 값을 고른다.
평가 사례마다 성공한 정책을 고르는 계산이 아니며, 한 경로에서 선택하는 정책은 하나다.

`hindsight = mean_path max(J8, J40)`

| 방법 | 관측 평균 성공률 |
| --- | ---: |
| 항상 40k까지 지속 | 34.075% |
| 항상 8k에서 중단 | 34.725% |
| 결과를 본 뒤 경로마다 좋은 쪽 선택 | **36.450%** |

사후 선택−항상 지속은 **+2.375%p**,
사후 선택−항상 중단은 **+1.725%p**다.
따라서 관측 평균이 더 높은 고정 행동과의 차이는 **+1.725%p**다.

### 사후 선택 값의 해석 제한

36.450%는 같은 결과를 보고 선택하고 채점한 값이다.
`mean max − max mean`은 계산 구조상 음수가 될 수 없으며,
양수라는 사실만으로 실행 가능한 선택기의 효과를 보여주지 않는다.
각 8k 상태의 미래도 한 번이고, 평가 오차를 포함한 관측값으로 최댓값을 골랐다.

따라서 +1.725%p를 다음 어느 것으로도 해석하지 않는다.

- 미래 모집단의 진짜 선택 가치 상한.
- 8k 시점에 얻을 수 있는 신호로 회수 가능한 이득.
- 다른 중단 시점 또는 다른 일정으로 전환했을 때의 성능 상한.
- 진단 비용을 지불한 온라인 알고리즘 성능.

그 대신 **현재 관측된 두 행동의 사후 차이도 특정 부모에 의존한다**는 투자 판단 자료로 사용한다.
+1.725%p가 본질적으로 무가치하다는 판정도 하지 않는다.
이 보조 분석에 새로운 oracle 신뢰구간을 붙여 모집단 효과처럼 보고하지 않았다.

## 3. 예측 대상은 손실 위험을 포함한 추가 학습의 순가치

패턴은 부모/8k/40k 순서이며 1은 성공이다.

| 후기 변화의 구성 | 전체 macro 기여 |
| --- | ---: |
| 후기 신규 성공 001 | +2.450%p |
| 부모 성공의 회복 101 | +1.600%p |
| 8k에 남아 있던 부모 성공의 상실 110 | −3.425%p |
| 초반 신규 성공의 상실 010 | −1.275%p |
| 합계 | **−0.650%p** |

후기 상실 4.700%p에는 중단으로 피할 수 있었던 사례가 들어 있지만,
중단하면 신규 성공·회복 4.050%p도 포기한다.
49번의 후속 질문에서 보존과 회복만 강조하면 **후기 신규 성공**이 빠지므로 표현을 보완한다.

> 추가 학습으로 얻는 신규 성공과 회복, 그리고 잃는 기존·신규 성공을 합친 순가치를 결정 시점에서 예측할 수 있는가?

손실 위험, 지속의 순가치, 다른 일정으로 전환하는 추가 가치는 별개의 대상이다.
손실 예측이 잘돼도 신규 성공·회복이 더 클 수 있고, 지속이 불리해도 전환이 이를 해결한다는 보장은 없다.
