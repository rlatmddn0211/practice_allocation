# 같은 8k 상태의 미래 반복 — 논문 방향 투자 판단 명세안

2026-10-20 KST. [50번 제안](../50_b_posthoc_concentration_review_v1/future_replication_proposal_ko.md)을 구체화했다.
이번 버전은 **명세안·기존 결과 기반 선택표 준비**다. 새 미래의 학습·평가·예약은 수행하지 않았다.
아래 수치 투자 기준과 기술 예산은 사용자의 정성적 권고를 구체화한 제안이며, 사용자 승인으로 기록하지 않는다.
새 미래 결과를 관측한 뒤 기준을 바꾸지 않는다.

## 1. 잠정적으로 고정할 질문

> 8k까지 학습한 동일한 상태에서, 추가 32k BP 학습의 순효과는 미래 난수를 바꾸어도 재현되는가?

`g(s8) = E_future[J40(s8, future)] − J8(s8)`.
여기서 상태는 이후 사용할 난수 stream과 분리한 학습·수집 상태다.
매 미래의 부호가 반드시 같아야 한다는 요구와, 기대 손익의 부호가 존재한다는 주장은 구분한다.
상태당 미래 두 번의 이 실험은 기대값·분산의 정밀 추정보다 추가 투자 여부를 판단하는 예비 검증이다.

연구의 큰 문제는 강한 고정 행동을 넘어서는 상태별 선택 가치다.
이번 행동은 **중단/기존 BP 지속**뿐이다. 다른 과제로의 배분 전환, replay 개입, 새 예측기, 온라인 진단 비용 회수는 이 범위에 없다.
논문의 형태는 아직 고르지 않는다. 반복성 결과 이후 실증·방법·원인 규명 중 근거가 강한 방향 하나를 검토한다.

## 3. 기존 미래로 행동을 고정하되 선택과 채점 사례를 분리

### 전체 O100 선택표 — 요청한 직접적인 보조 분석

기존 `J40−J8 > 0`이면 지속, 그 외에는 중단이다. 동률은 중단으로 고정한다.
전체 O100 기준은 중단 5개·지속 5개다.
새 미래 성적은 이 선택을 바꾸는 데 사용하지 않는다.

이 선택표는 과거 미래의 완성 성적을 사용한다.
따라서 **실제로 8k 시점에 실행할 선택 알고리즘이 아니라 미래 간 반응 이전의 진단**이다.

### 필요한 보완: 같은 J8 측정값의 재사용

기존 `old_J40_hat − J8_hat`으로 고르고, 새 `new_J40_hat − J8_hat`으로 채점하면
양쪽에 같은 `−epsilon8`이 들어간다. J8 측정 오차 항만 보면 양의 공분산이 생길 수 있다.
다른 정책의 사례 오차도 서로 연관되므로 전체 공분산이 반드시 그 항 하나와 같다는 주장은 하지 않는다.
새 학습 난수만 독립으로 바꿨다고 평가 사례까지 독립이 되는 것은 아니다.

관련 문헌도 공통 출발 점수 차감의 의존성을 줄이기 위해 독립 baseline 측정을 사용한다.
아래 반쪽 교차는 그 문제를 우리 평가 구조에 맞춰 처리하는 제안이다.
[What Will Post-Training Fix?, §3 Independent baselines](https://arxiv.org/html/2610.04978v1).

### 주 분석: 미래와 평가 사례를 함께 분리

기존 평가 규약의 구분을 그대로 사용한다.

- A: 각 과제 episode index 0–49.
- B: 각 과제 episode index 50–99.
- 방향 1: 기존 미래 A의 `J40−J8`로 선택 → 새 미래 B에서 채점.
- 방향 2: 기존 미래 B의 `J40−J8`로 선택 → 새 미래 A에서 채점.
- 두 방향 모두 필수이며 좋은 방향만 고르지 않는다.

총 20개의 고정 행동은 중단 11개·지속 9개다.
41012/4202만 반쪽 간 행동이 다르다. A 변화 +1.00%p로 지속, B 변화 −0.50%p로 중단이다.
이 차이는 작은 기존 차이에서 선택이 민감할 수 있음을 보여주는 기술적 확인이며 새 미래의 결과가 아니다.

[고정 선택표](results/20261020T085032Z_choice_preparation_16eed0c0/fixed_choices_ko.md),
[계산 가능한 CSV](results/20261020T085032Z_choice_preparation_16eed0c0/fixed_choices.csv)를 새 결과 전에 보존했다.
O100 전체 선택표의 결과는 보조로만 보고하고 주 분석 대신 유리한 쪽을 채택하지 않는다.

이 설계는 추가 평가 없이 동일 사례값의 직접적인 재사용을 피한다.
그러나 O100 전체는 이미 본 개발 bank다. 이번 질문·상태 집합을 정한 전체 과정의 독립성이나
새 부모 일반화를 보장하지 않는다. 두 교차 방향도 서로 완전히 독립된 실험으로 세지 않는다.

## 4. 비교량과 집계

새 미래에서 각 방향의 고정 선택에 따라 J8 또는 new_J40을 채점한다.
항상 중단은 같은 채점 사례의 J8, 항상 지속은 같은 채점 사례의 **새 미래** J40이다.
기존 미래의 34.075%를 새 미래의 지속 기준 대신 사용하지 않는다.

`G_stop = mean(selected_new_score − J8)`

`G_continue = mean(selected_new_score − new_J40)`

각 값은 네 과제 동일 가중 macro 성공률의 %p다.
부모 안에서 두 prefix 경로와 두 사례 방향을 평균한 뒤 부모 다섯 개에 동일 가중한다.
두 고정 행동과의 차이를 모두 보고한다.
더 좋은 고정 행동 대비 차이는 기술적으로 `min(G_stop, G_continue)`지만,
보고와 판정에서 두 원래 대조를 생략하지 않는다.

보조 분석은 다음에 한정한다.

- 각 상태의 기존/새 미래 후기 변화와 직접적인 `new_J40−old_J40`.
- 과제별 결과와 부모→8k→각 미래의 신규 성공·회복·두 종류 상실.
- 전체 O100 고정 선택표의 새 미래 성적.
- 부모 하나씩 제외한 다섯 경우. 제외 후 고정·선택 평균을 다시 계산하고, 더 좋은 고정 기준도 다시 선정.

기존/새 후기 변화의 단순 상관을 주된 반복성 증거로 사용하지 않는다.
상실 예측을 지속의 순가치 예측 또는 전환의 효능으로 바꾸지 않는다.

## 5. 불확실성과 투자 관문 제안

사례 재표집은 부모×과제×반쪽 안에서 50개 인덱스를 복원 추출한다.
각 인덱스는 같은 부모의 두 prefix 경로와 각 시점·미래 정책에 공통 적용한다.
고정 선택표는 재적합하지 않는다.
20,000회, seed 510303을 사용하며 두 주 대조의 공동 오차를 보존한다.

수치적으로 `theta=(G_stop,G_continue)`에 대해,
각 재표집에서 `max_b(theta_hat[b]−theta_star[b])`를 계산한다.
그 값의 95% 분위수 q를 빼서 `theta_hat[b]−q`를 두 대조의 공동 하한으로 보고한다.
이는 **학습된 정책·선택표에 조건부인 bootstrap 근사**다. 미래 학습의 변동이나 전체 개발 과정의 불확실성을 포함하지 않는다.

부모 평균 다섯 개의 3,125개 순서 있는 복원 재표집으로 2.5/97.5% 기술 구간도 보고한다.
소수 부모의 구간은 별도 한계로 명시하며 새 미래 학습 분산을 정밀하게 추정한 것으로 취급하지 않는다.

아래는 **사용자 확인 전의 투자 기준 제안**이다. 수치가 이론적으로 최적이라거나 기존 실험의 사전 기준이었다고 주장하지 않는다.
1%p는 사소한 양수만으로 확대하지 않기 위한 실용 문턱, 2/3은 한 부모 집중을 제한하기 위한 규약이다.

| 조건 | 제안 기준 |
| --- | --- |
| 크기 | 주 분석의 G_stop, G_continue가 각각 **+1.0%p 이상** |
| 사례 불확실성 | 위 두 조건부 공동 하한이 각각 **0보다 큼** |
| 부모 제거 | 어느 부모 하나를 제외해도 두 비교의 평균 이득이 **각각 양수** |
| 집중도 | 각 대조에서 최대 부모의 양의 기여 / 모든 부모 양의 기여 합이 **2/3 이하** |
| 무결성 | 동일 상태 복원·난수 분리·평가 일치·예산 검사를 모두 통과 |

집중도는 각 비교별 부모 평균 이득 `d_p`로 `max(max(d_p,0))/sum(max(d_p,0))`를 계산한다.
분모가 0이면 미통과다. 음수 기여와 모든 부모 원값도 함께 공개한다.
부모 제거 검사는 부모 자료를 완전히 제거하되 이미 동결한 다른 상태의 행동을 재학습하지 않는다.
현재 절차에는 부모 간 적합이 없기 때문이다.

모든 조건을 충족할 때만 후속 투자 검토의 근거가 강화된 것으로 읽는다.
부모 구간이 넓을 수 있고 상태당 미래 두 번뿐이므로, 관문 통과도 모집단 효과의 확증이나 온라인 알고리즘 성공이 아니다.
미통과·불명확은 **추가 투자 보류**다. 선택 가치가 없다는 증명은 아니다.
자동으로 반복 수·특징·행동·시점·문턱을 바꾸지 않는다.

| 결과 | 다음 판단 |
| --- | --- |
| 두 고정 행동 대비 이득과 분산된 기여가 관문을 충족 | 사전 정보·새 부모·조건 설명 중 다음 연구 목적 하나를 선정할 근거 |
| 순손익은 비슷하게 반복되지만 거의 모두 같은 행동이 유리 | 상태별 선택 확대보다 고정 행동의 적용 범위를 우선 검토 |
| 반전·한 부모 집중·작은 차이·넓은 사례 불확실성 | 현재 설정의 추가 투자 보류 |
| 기술 무결성 실패 | 과학적 음성 결과로 세지 않고 실행 중단·원인 보고 |

## 6. 동일 상태와 미래 난수의 기술 계약

기존 모델·replay를 초기화하거나 `start_branch`를 호출하지 않는다.
현재 함수는 schedule 재생성, task visits 초기화, replay branch 경계 변경을 하므로 이 목적과 맞지 않는다.
새 실행을 하게 되면 독립 버전에서 복원 후 **허용한 RNG 필드만 교체**해야 한다.

보존 대상은 actor/critic/target, optimizer와 entropy 상태, replay 내용·위치·sample 카운터·branch 경계,
절대 step/update, 수집 누적량·task visits, schedule 후보·기존 block·cursor·blocks_generated다.
episode 경계와 warm-up 종료를 확인하며 비활성 warmup RNG도 그대로 둔다.
환경 내부의 진행 중 에피소드가 있으면 이 복원 규약을 적용하지 않는다.

미래 root는 `NumPy SeedSequence([510202,51,parent,prefix]).generate_state(1)[0]`로 제안했다.
global Python/NumPy/Torch CPU/CUDA 및 이후 환경 reset root를 새 root로 바꾼다.
schedule RNG만 기존 `derived_seed(new_root,10)` 규약으로 교체하며 이미 생성된 순서는 그대로 둔다.
이후 환경 seed는 새 root·domain20·task·보존한 visit 번호를 사용한다.
[실제 제안 seed·기존 seed·checkpoint·bank 목록](results/20261020T085032Z_choice_preparation_16eed0c0/state_manifest.json)에 고정했다.

여러 난수원을 함께 바꾸므로 이 실험으로 exploration/replay sampling/과제 순서 중 어느 것이 원인인지 분리했다고 주장하지 않는다.
그 목적에는 별도 요인 개입이 필요하다.

실행 전에는 원본 hash를 확인하고, RNG 교체 전후의 비난수 상태 fingerprint가 동일한지 검사한다.
동일 RNG 복원 두 번의 짧은 학습 trace 일치, 새 RNG의 비난수 상태 보존, horizon에 따른 규칙 불변,
평가 seed/초기 상태 일치도 확인해야 한다.
이번 준비는 CSV·manifest만 읽었으며 모델/replay 복원이나 이 실행 검사를 수행한 것은 아니다.

## 7. 기술 예산 제안과 비용 회계

본 실행 2.32M과 구분해 **기술 검사 최대 10k 환경 step**을 제안한다.
이는 새로 제안한 한도이며 이미 승인되거나 지출한 비용이 아니다.
본 실행과 합하면 최대 **2.33M 환경 step**이다.
기술 복제 학습·평가·실패 비용을 실제 계측하고 소진 시 멈춘다.
추가 자동 재시도 예산은 0이다. 중단된 학습의 반복 지출이 본 한도를 넘으면 임의로 재시작하지 않는다.
모든 시도·source snapshot·hash·checkpoint를 새 경로에 보존한다.

이 실험은 오프라인 연구 비용을 지불해 새 미래를 전부 관측한다.
과거 미래로 만든 행동표의 운영 진단 비용을 0으로 주장하지 않는다.
