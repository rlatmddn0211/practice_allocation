# 선택 가치 연구의 수정 명세

2026-10-19. [항목별 검토](feedback_disposition_ko.md), [기계 판독 설정](protocol.json). 이 버전은 41번을 대체한다. 원래 파일럿과 39·41·42번의 소스·결과는 보존한다.

## 중심 질문과 그대로 유지하는 범위

강한 고정 연습 방법을 넘어서는 선택 가치가 어떤 학습 상태에 존재하며, 그 가치를 알아내는 진단 비용을 회수할 수 있는가? 이를 **선택 여지 → 결정 시점 정보의 식별력 → 새 부모에서 비용 회수**로 나누어 검증한다.

B의 DO/DC/PU/BP, 공유 SAC, 기존 dense reward·500-step 학습·FIFO replay·업데이트 규약을 유지한다. 주 목적은 네 과제 동일 가중 최종 성공률이다. 과제별 변화·부모 대비 손실·원래 seed별 결과·비용·불확실성을 함께 기록한다. 고정 방법 발견과 상태별 선택 개선을 구분한다.

## 1단계: 학습 셀은 유지하고 저장·분석을 보완

부모 seed 41011–41015를 각각 Uniform 200k 사전학습한다. 후속 라벨 4201/4202마다 BP 고정 집중(`dose625`), 4k 교대, 혼합을 각각 +40k 실행한다. 부모나 결과를 선별하지 않는다. **30분기, 사전학습 포함 2.2M 학습 step, 부모5+분기30의 O100 평가상한 7.0M, 합계 9.2M 환경 step 상한**이다. 기술 검사·중단 재시도는 별도 계상한다.

BP 집중은 원래 F08의 **8k/16 episode 셔플 블록**을 유지한다. 교대와 혼합의 40k 과제별 총 수집량도 기존과 같다. 교대−혼합 평균 우위는 전체 연구의 통과 조건이 아니다.

분기 전체 상태 저장은 **4k / 8k / 20k / 36k / 40k**다. 사전학습 20k 간격은 그대로다. 36k 저장은 추가 학습·중간 평가가 없고 저장 용량과 시간이 증가한다. 저장·복구가 learner, optimizer, replay, collector, RNG를 바꾸지 않는지 확인한다. 36k에서 BP의 8k 블록이 반만 진행되었더라도 그 순서와 RNG를 그대로 보존한다.

### 분석을 하나로 고정

- 반복 가능한 2%p 차이는 **각 부모·각 후속 반복의 전체 O100 macro** 차이다. 성공 수 400개를 4로 나누어 % 단위 macro를 계산한다. 반쪽 성적을 이 기준에 쓰지 않는다.
- 사례 반쪽은 과제별 index 0–49와 50–99다. 한 반복의 선택 반쪽에서 부모별 방법을 고르고, 다른 반복의 반대 반쪽에서 채점한다.
- 부모 제외 고정 방법은 **현재 채점 부모를 제외한 다른 네 부모**의 동일 선택 반쪽에서 두 반복을 먼저 평균하고, 부모들을 동일 가중해 고른다. 동점 순서는 BP→교대→혼합이다.
- 부모마다 두 반복 방향×두 반쪽 방향의 네 채점값을 평균한 뒤, 부모 다섯 개를 동일 가중한다. 독립 단위는 부모이며 네 값이나 평가 episode를 독립 부모로 세지 않는다.
- 부모 하나를 제외하는 민감도는 해당 부모를 자료에서 완전히 제거하고 **남은 네 부모로 교차 선택과 고정 기준 선정을 다시 실행**한다. 남은 대상 부모의 고정 기준은 나머지 세 부모로 선정된다. 사전 고정 BP는 유지한다. 이미 계산한 부모 이득 중 하나만 지우는 방식은 보조 결과로 별도 표기한다.

진행 기준은 (1) 같은 방법 쌍에 대해 두 반복 모두 2%p 이상으로 반대 우열을 보이는 부모가 각각 하나 이상, (2) 교차 선택 이득이 BP와 부모 제외 고정 기준보다 평균 양수, (3) 전체 부모 제외 재적합 민감도에서 두 이득 모두 양수다. 이것은 자원 투자를 위한 탐색 기준이며 유의성 검정·충분한 검정력·효과 부재의 증명이 아니다. 1단계 미통과로 8k 이후 전환 가치를 부정하지 않는다.

부모 유지 정책은 별도 참고 행동이다. 그 선택만 유리하면 전환 연구가 통과한 것으로 바꾸지 않고 중단 문제로 구분한다.

## 2단계: 8k 이후 28k를 주 개발 대상으로

1단계 전체 평균 1위 F*, 나머지 중 1위 A*를 고정한다. 동점 우선순위는 BP→교대→혼합이다. 이 쌍이 1단계에서 반복 우열 교차를 보인 쌍과 같다고 가정하지 않는다.

부모당 두 후속 학습에서 생성된 F*8k 상태, 총 열 개를 사용한다. 각 **동일 전체 8k 상태**에서 유지와 전환 미래를 짝지어 비교한다. 유지는 검증된 1단계 36k 결과 상태를 재사용하고, 전환은 A*로 +28k 실제 실행한다. 기존 A* 시작 일정의 결과를 이어 붙이지 않는다. actor/critic/entropy/optimizer/replay, reset 방문 수, 학습 RNG를 리셋하지 않는다. 일정 generator의 난수 상태를 보존하고 전환 phase만 명시한 시작 phase로 설정한다.

각 8k 상태에서 D bank 과제별 2사례, 각 500-step을 끝까지 실행해 **4k 진단**을 실제 지불한다. 성공은 500-step 안의 any-success다. 진단을 replay에 넣지 않고 학습 전체 상태·RNG를 보존한다. 부모 초기 평가나 미래 성적을 무료 입력으로 제공하지 않는다.

주 목표는 **동일 8k 이후 +28k 유지와 +28k 전환의 O100 차이**다. 두 행동의 총학습36k 정책 20개를 새 O100으로 평가한다. 비용은 신규 전환280k+진단40k+평가상한4.0M=**4.32M 환경 step**이다. 유지36k를 정확히 재사용할 수 없으면 이 산식은 성립하지 않으며, 추가 학습 전에 변경 명세와 비용을 기록한다. +32k 실행·평가는 이번 기본안에 포함하지 않는다.

### 28k 종료 규약

원래 생성한 블록 순서의 정확한 prefix를 사용하고 28k에서 종료한다. quota를 맞추려고 재배분·재셔플하지 않는다. 500-step episode 경계이며 8k 블록 경계일 필요는 없다. 실제 과제별 수집량을 기록한다.

교대로 전환하면 BP phase부터 시작한다. +28k는 BP phase 네 개와 DO phase 세 개다. 이때 suffix 수집량은 BP11.5k/DO9.5k/DC3.5k/PU3.5k이며, 혼합의 BP10.5k/DO10.5k/DC3.5k/PU3.5k와 다르다. 따라서 실제 방법 비교로 해석하고 동일 총량의 순수 순서 대조라고 부르지 않는다. dose625의 부분 블록 quota는 해당 seed가 생성한 원래 순서에 따라 달라질 수 있다.

### 점수·후보·적합을 동결

과제별 두 진단 사례의 성공 수를 s_DO, s_DC, s_PU, s_BP∈{0,1,2}라 두고 다음 점수 하나를 사용한다.

`q = 3*s_BP - s_DO - s_DC - s_PU`

`score = q/6 = BP 성공률 − 나머지 세 과제 평균 성공률`

q는 −6부터6까지의 정수, 점수는 최대 **13개 값**이다. 이 점수는 B의 기존 BP 단서에서 고른 하나의 후보이며 유효한 요인으로 확인된 것은 아니다. F*가 BP가 아니어도 점수 정의를 결과에 맞춰 바꾸지 않는다.

후보는 가능한 점수 사이의 경계 `{−11,−9,…,9,11}/12` 열두 개와 두 방향(점수 높으면 전환 / 낮으면 전환), 그리고 항상 유지·항상 전환이다. 총 **26개**다. `2*q`와 홀수 경계 분자를 비교하므로 부동소수점 경계나 정확히 같은 값의 처리가 모호하지 않다.

적합 목적은 선택한 행동의 +28k 최종 macro 성공률을 부모 동일 가중으로 최대화하는 것이다. 각 부모에 상태 두 개, 각 결과에400 episode가 있으므로 정수 성공 수 합으로 동일 목적을 정확히 계산한다. 동점이면 (1) 적합 상태에서 전환 횟수가 적은 규칙, (2) threshold보다 상수 행동, (3) 사전 후보 순서: 항상 유지→항상 전환→높음 방향 경계 내림차순→낮음 방향 경계 오름차순을 적용한다. 전체 동점에서는 항상 유지가 선택된다. 불완전한 진단은 임의 대체하지 않고 기술 실패로 기록한다.

부모 하나를 제외한 나머지 네 부모의 여덟 상태에서 26개 중 하나를 적합한 뒤, 제외한 부모의 두 상태에 적용한다. 두 상태의 성적을 부모 안에서 평균하고 부모들을 동일 가중한다. 민감도는 부모를 완전히 제거한 뒤 남은 부모에서 적합과 제외 채점을 다시 실행한다. 이후 최종 진행 조건을 통과하면 열 상태 전부로 한 번 적합한 단일 규칙을 source/input hash와 함께 동결한다. 새 부모 결과를 보고 방향·점수·threshold를 변경하지 않는다.

진행 조건은 전체 O100에서 두 상태 모두 유지가 최소2%p 좋은 부모와 전환이 최소2%p 좋은 다른 부모가 각각 하나 이상이고, LOPO 규칙의 이득이 항상 유지·항상 전환보다 모두 평균 양수이며, 부모 전체 제거 후 재적합에서도 두 이득이 모두 양수인 것이다. 탐색 투자 기준이며 확증 검정이 아니다. 항상 전환으로 충분하면 좋은 고정 전환의 발견으로 기록한다.

### 해석 범위

F*/A*는 모든 1단계 부모로 선정했다. 따라서 2단계 LOPO는 **선정된 일정 쌍과 상태 집합에 조건부인 개발 평가**다. 새 O100을 써도 일정 선정까지 독립 검증으로 바뀌지 않는다. 이를 해결하려고 지금 중첩 교차검증용 학습을 추가하지 않는다.

열 개 상태는 부모당 서로 다른 두 8k 상태이며 각 상태에 미래 한 쌍이다. 같은 부모의 두 상태에 걸친 반복을 확인할 수 있으나, 동일한 한 8k 상태에서 여러 미래 seed의 기대 전환 이득을 반복 추정한 것은 아니다. 음성 결과는 우선 이 일정 쌍·이 진단·이 규칙 집합에 제한된다.

## 3단계: 다섯 방법으로 정보 가치와 비용 회수를 분리

새 부모는 1·2단계의 선택·적합에 사용하지 않는다. F*/A*·최종 규칙·평가 사례·표본 수·실용적 효과·불확실성 절차를 새 결과 전에 동결한다.

| 논리적 방법 | 학습 | 진단 | 운영 예산 |
| --- | --- | ---: | ---: |
| 진단 없는 고정 유지 | F*40k | 0 | 40k |
| 진단 없는 고정 전환 | F*8k→A*32k | 0 | 40k |
| 진단 기반 선택 | F*8k→선택 행동28k | 4k | 40k |
| 진단 후 항상 유지 | F*8k→F*28k | 4k | 40k |
| 진단 후 항상 전환 | F*8k→A*28k | 4k | 40k |

정보의 가치는 선택 방법이 **같은 비용의 항상 유지와 항상 전환 모두**보다 좋은지로 판정한다. 순실익은 선택 방법이 **진단 없는 고정 유지와 고정 전환 모두**보다 좋은지로 판정한다. 각 비교를 사전에 정하고 새 결과에서 약한 기준만 고르지 않는다. 유지의 진단 비용 효과는 유지36k−유지40k, 전환의 비용 효과는 전환36k−전환40k로 각각 보고한다.

### 공유 실행의 조건과 비용

진단이 전체 학습 상태/RNG를 바꾸지 않고, update 규칙이 종료 길이에 의존하지 않으며, 유지·전환의 두 미래가 동일한 8k 전체 상태에서 시작하는지 먼저 검증한다. **진단 직후 두 미래의 학습이나 최종 성능 확인 전에** 규칙 ID·입력·state/source hash·선택 행동을 변경 불가능한 기록으로 남긴다.

이 조건이면 공통8k→진단4k 이후 유지32k와 전환32k 두 경로를 실행하며, 각 경로의 suffix28k/32k(총학습36k/40k)를 저장한다. 네 최종 정책을 같은 O bank로 평가한다. 적응형은 미리 선택해 기록한 36k 정책과 동일하므로 그 정책의 평가를 공유할 수 있다. 미래 점수를 보고 적응형 행동을 고르는 것은 금지한다.

부모×후속 반복당 실제 연구 학습은 `8k+32k+32k=72k`, 공유 진단은4k, 합계 **76k**다. 각 방법의 논리적 운영 비용40k와 다섯 방법의 비용 표는 별도로 유지한다. 네 최종 정책의 O100 평가 상한은800k이며 적응형이라는 이름으로 같은 정책을 별도 독립 표본으로 세지 않는다.

새 부모 N개, 부모당 후속 반복 R개일 때 사전학습은200k×N, 공유 학습·진단은76k×N×R, 부모 평가 상한200k×N, 네 최종 정책 평가 상한800k×N×R이다. 기술 검사와 재시도는 별도다. N과 불확실성 절차는 아직 미정이며 2단계 변동·필요 정밀도로 결정한 후 동결한다. 이 문서는 미정 규모의 3단계를 예약하지 않는다.
