# 추가 연습 배분 연구의 구체화 과정

기록 기준일은 2026-10-14다. 현재 연구 질문은 **사전학습된 공유 정책에서, 남은 예산을 어떤 과제에 얼마나 배분해야 전체 과제의 최종 성능이 가장 좋아지는지 판단하는 기준을 찾는 것**이다. 그 기준을 적은 비용으로 측정하고 실제 배분에 사용했을 때 기존 방법을 이기는지까지 검증한다.

## 현재 연구 질문

> 공유 정책의 추가 강화학습에서, 국소적인 학습·전이 신호는 어떤 조건에서 남은 예산의 최종 성능 이득을 잘못 예측하는가? 제한된 진단으로 그 오류를 보정하면, 진단 비용을 포함해 기존 배분보다 좋은 결과를 얻을 수 있는가?

전체 성능은 현재 규약의 과제별 성공률 동일 가중 평균으로 둔다. 추가 학습 전 대비 절대 변화와 Uniform 대비 차이를 함께 본다. Uniform을 이겨도 출발점보다 낮을 수 있으므로 두 값을 구분한다. 다른 과제에 발생한 손실도 전체 변화에 포함한다.

## 세 가지 기본 후보 요인

| 후보 요인 | 측정하려는 것 |
|---|---|
| 학습 반응성 | 짧게 더 연습했을 때 해당 과제가 얼마나 개선되는가 |
| 다른 능력의 변화 | 그 연습으로 다른 과제의 성능이 얼마나 좋아지거나 떨어지는가 |
| 효과의 지속성 | 연습을 이어갈수록 개선 속도가 유지되는가, 포화되거나 역전되는가 |

이 세 항목은 관측할 학습 반응의 큰 분류다. 반응을 좌우하는 학습 상태나 진단 신뢰도를 모두 열거한 목록은 아니다. 예를 들어 다른 과제의 성능 변화는 관찰할 결과이고, gradient 간섭은 그 변화를 설명할 수 있는 후보 기전이다. 둘을 같은 수준의 독립 요인으로 세지 않는다.

E3 B는 현재 출발 상태와 예산에서 잘 반응한 과제가 있음을 보여준다. C seed 13의 PickPlace 집중에서는 DO가 81.00%에서 87.33%로 좋아지면서 BP가 85.00%에서 45.00%로 하락했다. 한 과제의 긍정적인 수치만으로 전체 손익을 판단하기 어려운 사례다. 이 관찰 자체로 직접 전이나 특정 gradient 기전을 확정하지 않는다.

## 후보에서 실제 배분까지의 검증 순서

1. **후보 정의:** 왜 최종 이득과 관련될 수 있는지 설명하고, 반증 가능한 예측과 측정 항목을 정한다.
2. **측정 가능성:** 배분을 결정하는 시점에 얻을 수 있는 정보인지 확인한다. 40k 최종 성능으로 만든 요인을 같은 40k 이득의 예측 입력으로 사용하지 않는다.
3. **예측 검증:** 현재 성능과 단기 개선량만 사용하는 기준에 후보를 추가했을 때, 새로운 출발 상태에서 최종 이득·순위·선택 손실의 예측이 나아지는지 본다.
4. **배분 검증:** 진단을 포함한 동일 총예산에서 최종 전체 성능이 Uniform, 실패율 기반 배분, 강한 고정 배분과 관련 기존 방법보다 좋아지는지 확인한다.

예측 오차가 작아져도 의사결정을 바꾸지 못하거나 진단이 학습 예산을 많이 소비하면 실제 이득이 없을 수 있다. 진단 정확도와 비용을 회수한 성능 이득을 각각 검증한다. 학습·진단의 환경 step을 합산하고 GPU·wall time은 별도 기록한다. 서로 다른 단위를 임의로 더하거나 환경 step을 성공률에서 직접 빼지 않는다.

## 현재 증거와 다음 판단의 경계

E0–E3는 탐색 자료이며, 지금 만든 가설의 새 확인 자료로 소급 지정하지 않는다. E1·E2는 같은 원래 seed의 상태를 재사용하며, E3의 B·C도 같은 세 seed 번호를 사용한다. checkpoint, continuation, 평가 사례를 독립 사전학습 반복으로 세지 않는다. 원래 seed를 통째로 제외한 검증과 과제 구성 제외 검증이 필요하지만, 현재 seed 세 개로 안정적인 확인 효과를 주장하기 어렵다.

다음 판단은 후보들이 단순 기준보다 정보를 더 주는지, 그 정보가 적은 비용으로 측정 가능한지다. 예측 정보가 없으면 해당 후보를 제외하고, 단순 고정 배분이 충분하면 그 조건을 함께 보고한다. 예측이 가능해도 비용 때문에 실제 배분이 나빠지면 비용을 회수하지 못한 결과로 기록한다.

기존 파일럿, E0–E3 규약, 19번 제안과 이전 결과는 보존한다. 이 버전은 연구 근거 정리이며 새로운 사전학습·probe·환경 평가를 실행하지 않는다.
