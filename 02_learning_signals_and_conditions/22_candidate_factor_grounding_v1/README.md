# 추가 연습 배분의 후보 요인과 연구 근거

E0–E3에서 얻은 관찰과 2026-10-14까지의 연구 구체화 과정을 보존한다. 기본 세 요인인 학습 반응성·다른 능력의 변화·효과의 지속성을 유지하면서, 이를 설명하거나 측정의 신뢰도를 판단할 추가 후보를 정리한다.

추가로 확인한 구현 사실은 **집중 과제 수집 비중 62.5%가 학습 batch의 같은 비중을 뜻하지 않는다**는 점이다. 72개 집중 분기의 실제 batch 샘플 누적 카운터를 대조하면 처음 20k 구간의 집중 과제 비중은 평균 28.76%, 다음 20k는 36.26%, 전체 40k는 32.51%다. 이 노출 차이를 확인했지만, 그것이 배분 순위나 성능 손실을 설명하는지는 아직 검증하지 않았다.

`audit_replay_exposure.py`는 표준 라이브러리만 사용해 이전 실행을 읽으며 이전 구현을 import하지 않는다. 매번 새로운 결과 디렉터리에 실행 소스·입력 hash·검사 결과를 보존한다. 1,290개 검사를 통과했고 신규 학습과 환경 평가는 0이다. 모델이나 replay 파일을 역직렬화하거나 실행 중인 learner를 변경하지 않았다.
