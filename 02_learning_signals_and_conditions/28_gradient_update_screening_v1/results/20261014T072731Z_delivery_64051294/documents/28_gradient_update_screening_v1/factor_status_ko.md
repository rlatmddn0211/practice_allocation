## F01 기록

- **질문:** 과제별 초기·20k 성공률과 순하락을 통제한 뒤에도, 기존 성공의 상실·새 성공의 획득 정보가 남은 이득을 예측하는가.
- **정의:** L/G의 차이는 순변화와 같으므로 두 요인으로 세지 않는다. `min(L,G)/N`의 초과 사례 교체를 집중 대상·나머지 평균 두 특징으로 추가했다. 초기 성공 0의 조건부 상실률은 결측으로 남겼다.
- **자료:** A200/A400/B200/C200, 원래 seed 11/12/13, A 후속 2101/2102/2103·B/C 후속 2301/2302/2303. 12개 상태·9개 이력·3개 원래 seed 블록, 148,800개 기존 평가 행.
- **관찰:** 720개 task·분기 중 209개에서 주변 성공률 이상의 자유도가 있고 178개에서 실제 초과 교체가 있었다. 511개는 성공률만으로 이미 정해진다.
- **주 결과:** Profile 대비 선택 이득 **−0.074%p**, MAE 6.452→6.537%p. 선택 변경 2/36, 원래 seed별 0/0/−0.222%p. 교차 후속 반복 이득 −0.148%p.
- **불확실성:** 고정 선택의 O 사례만 재표집한 구간 [−0.278,+0.130]%p. 학습·예측기·진단 선택 불확실성을 포함하지 않으며 새 확인 표본도 아니다.
- **불리한 결과:** D 반쪽 특징도 같은 반복에서 음의 추가 이득. 주 결과는 Greedy20보다 −0.241%p. 성공률 보존 손실의 선택 평균도 개선되지 않았다.
- **비용·검증:** 새 환경·지속 update 0. 최종 주 분석 1.090초. 원본부터 독립 검산 **97,977개 검사 통과**. 첫 분석의 Greedy20 부모 평가 비용만 정정했고 이전 출력은 보존했다. 기술 분석 실패는 없었다.
- **판정·한계:** 선별 기준 미통과, 이번 지표 채택 보류. 20k는 원래 제안한 값싼 4k 진단이 아니다. 바닥·천장 성능, 세 원래 seed, 고정 작은 모델의 제약이 있다.
- **다음 조건:** 중간 성공률 상태의 실제 짧은 진단에서 특징을 고정한 뒤 새 원래 seed의 추가 선택 가치와 총비용을 확인해야 한다. 후속 실행은 이번 기록으로 자동 승인되지 않는다.

## F04 기록

- **질문:** 현재 성능·단기 변화·critic 진단 이후에도 과제 간 gradient와 저장된 Adam 방향·크기가 전체 최종 이득의 선택을 개선하는가.
- **정의:** actor/critic gradient를 분리했다. 실제 과거 0→20k sample 노출로 가중한 gradient를 복제 Adam에 적용하고, 별도 episode panel의 `−g·δ / loss RMS`를 계산해 actor·critic 두 특징을 만들었다. 완전한 결합 SAC update나 성공률 gradient는 아니다.
- **자료:** F01과 같은 원래·후속 seed 및 상태, 부모·20k 모델 192개. 모델별 replay panel 합 1,572,864항목, gradient 24,576회, 복제 Adam step 12,288회.
- **관찰:** task 간 raw cosine 음수 비율 actor 35.59%·critic 29.39%. task norm 최대/최소 비율 중앙값 2.24·5.43배. 별도 panel의 주 지표 상관 0.827·0.944, batch 부호 혼합 23/180·51/180.
- **주 결과:** CriticBase 대비 **+0.065%p**, MAE 6.461→6.493%p, 선택 변경 3/36. 원래 seed별 +0.194/0/0%p, A200 −1.833·A400 +2.222·B/C 0%p. 다른 후속 반복 +0.111%p.
- **불확실성:** 고정 선택의 O 사례 구간 [−0.167,+0.315]%p. 세 원래 seed만으로 일반 효과의 유의성이나 무효과를 확정하지 않는다.
- **불리한 결과·민감도:** 단순 cosine/raw 방향의 교차 반복 이득 −0.444/−0.500%p. 반대 panel Adam −0.407%p. 주 결과는 Greedy20보다 −0.102%p. 균등 가중 Adam과 같은 선택이라 관측 노출 가중의 추가 효과도 확인되지 않았다.
- **비용·검증:** 본 측정 wall 334.47초, CPU 168.22초, CUDA 진단 구간 합 211.27초. 새 환경·원본 지속 update 0. 최종 측정 검산 **87,608개**, 예측 검산 **26,858개** 통과. 반올림·JSON 저장 실패 2회를 보존했다. 저장 실패 시도의 정확한 최종 시간 요약은 없다.
- **판정·한계:** 평균 +1%p·둘 이상의 원래 seed 양수 기준 미통과. 이번 두 요약 채택 보류. 20k의 local surrogate loss, 기존 replay, 고정 모델·세 seed에 한정한다. 음의 cosine을 망각의 원인으로 단정하지 않는다.
- **다음 조건:** 실제 작은 probe에서 신호·panel 반복성을 고정하고 새 원래 seed의 추가 선택 이득을 확인해야 한다. gradient 조작의 기전 실험과 비용 포함 배분 비교는 별도 미실행 단계다.
