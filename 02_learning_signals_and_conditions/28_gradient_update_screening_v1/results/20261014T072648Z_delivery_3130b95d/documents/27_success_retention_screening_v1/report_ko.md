# F01: 기존 능력 취약성의 추가 가치는 확인됐는가

**성공률이 같아도 성공한 사례가 달라지는 현상은 있었다. 그러나 그 정보를 추가했을 때 최종 예측과 연습 선택이 좋아지지는 않았다.** 주 선택 이득은 −0.074%p, 예측 오차는 6.452→6.537%p였다. 이번 정의의 취약성 요약은 핵심 요인 채택을 보류한다. F01 전체가 무의미하거나 망각이 없다는 결론은 아니다.

## 이번 검증이 다룬 범위

원래 설계의 공통 4k 진단을 새로 실행하지 않았다. 기존 E1 A200/A400와 E3 B200/C200의 **부모→20k** 평가를 짝지어, 같은 분기의 40k 결과를 예측하는 탐색 분석이다. 원래 seed 11·12·13, 후속 seed A의 2101·2102·2103 및 B/C의 2301·2302·2303을 사용했다. 출발 상태 12개는 부모 이력 9개와 원래 seed 세 블록에 속한다. 180개 분기나 720개 과제·분기 행을 독립 사전학습 반복으로 세지 않는다.

원본 평가 372개·148,800 episode 행의 SHA-256, 상태 일치, 성공 수와 실제 평가 길이를 검사했다. 같은 task·초기 상태 hash·평가 seed끼리 짝지었다. 기존 F07과 같은 결과 독립 hash 정렬로 과제당 100개 사례를 D50/O50으로 나눴다. D는 입력·개발 목표, O는 최종 채점에만 사용한다. 이미 연구 중 관찰했던 자료를 나눈 것이므로 새 확인 표본은 아니다.

## 무엇을 새 정보로 정의했는가

각 D50에서 다음 네 경우를 셌다.

| 전후 결과 | 의미 |
| --- | --- |
| 성공→성공 | 기존 성공 보존 |
| 성공→실패 | 잃은 성공 L |
| 실패→성공 | 새 성공 G |
| 실패→실패 | 계속 실패 |

성공률 변화는 `(G−L)/50`이다. L과 G를 별개 독립 요인으로 세면 같은 정보를 중복 평가하게 된다. 추가 특징은 **초과 사례 교체 `min(L,G)/50`**로 정했다. 이는 `L/50 − max(p0−p20,0)`와 같아서, 순하락만으로 불가피한 성공 상실을 제외한다.

이 값의 가능한 최대치는 `min(p0,p20,1−p0,1−p20)`다. 초기 또는 20k 성공률이 0%·100%이면 추가 자유도가 사라진다. ‘이전에 성공했던 사례 중 상실 비율’도 별도 기록하되, 초기 성공 수가 0인 240행은 결측으로 보존했다. 0으로 대체하지 않았다.

초기·20k 성능을 충분히 통제하기 위해 기준선 Profile은 네 과제 각각의 초기 성공률·변화·순하락을 모두 입력한다. 집중 대상은 첫 위치, 나머지는 초기·현재 성공률 순으로 정렬하고 Uniform은 네 과제를 정렬한다. 과제명·구성명·seed를 입력하지 않는다. 추가 F01 특징은 집중 과제와 나머지 과제의 평균 초과 교체량 두 개다. Uniform에서는 두 역할 모두 전체 평균을 사용한다.

## 관찰된 사례 교체

| 구성·출발점 | 과제·분기 행 | 추가 정보가 가능한 행 | 실제 초과 교체가 있는 행 | 평균 초과 교체 |
| --- | ---: | ---: | ---: | ---: |
| A200 | 180 | 69 | 57 | 2.76%p |
| A400 | 180 | 49 | 46 | 1.32%p |
| B200 | 180 | 32 | 23 | 1.41%p |
| C200 | 180 | 59 | 52 | 2.14%p |
| 전체 행 수 | 720 | 209 | 178 | 구성별 수치는 단순 행 평균 |

**511/720행(70.97%)에서는 초과 교체량이 성공률 두 값에 의해 이미 정해진다.** 현재 자료의 바닥·천장 성능은 취약성의 추가 가치를 판별하기에 제약이 있다. 반면 178행에서는 순변화에 가려진 교체가 실제로 존재한다. 이 관찰만으로 이후 망각의 원인 또는 좋은 배분 기준이라고 말할 수는 없다.

## 미래 예측과 실제 선택 채점

원래 seed 하나를 모든 구성·출발 시점에서 통째로 제외하고 나머지 둘로 적합했다. 같은 이력의 A200/A400를 서로 다른 fold에 넣지 않았다. 표준화는 학습 fold에서만 하며, 고정 ridge penalty 1을 사용했다. 예측 목표는 같은 분기의 D40−D20이고 예상 최종값은 D20에 예측 잔여 이득을 더한 값이다. 모델·정규화·특징을 결과에 맞춰 탐색하지 않았다.

각 제외된 출발 상태·후속 seed에서 다섯 배분 중 예상 최종값이 가장 높은 것을 고르고, **그 선택의 실제 같은 40k 분기**를 O로 채점했다. 다른 분기 상태를 이어 붙이지 않았다. A/B/C를 동일 가중하고 A200/A400는 A 안에서 반씩, seed와 후속 반복은 동일 가중한다.

| 선택 방법 | 최종 macro 성공률 | Profile 대비 선택 이득 | O40 예측 MAE |
| --- | ---: | ---: | ---: |
| Uniform | 42.398% | −2.722%p | — |
| 초기 실패율 집중 | 41.713% | −3.407%p | — |
| 다른 원래 seed에서 고른 고정 배분 | 42.898% | −2.222%p | — |
| Greedy20: 20k 성공률 최대 | **45.287%** | +0.167%p | — |
| 집중/나머지 평균만 쓰는 Role | 44.889% | −0.231%p | 6.378%p |
| 과제별 성능 Profile | 45.120% | 기준 | 6.452%p |
| Profile + F01 | 45.046% | **−0.074%p** | **6.537%p** |

F01을 추가하면 36건 중 두 선택이 달라진다. 원래 seed 11/12/13의 추가 이득은 **0.000 / 0.000 / −0.222%p**이며, 구성별 A200/A400/B200/C200은 **0.000 / 0.000 / −0.222 / 0.000%p**다. 최악 과제 하락의 선택 평균도 Profile과 같은 11.667%p로 개선되지 않았다.

고정된 모델·D 사례·선택에 대해 O 사례만 함께 재표집한 조건부 95% 구간은 **[−0.278, +0.130]%p**다. 학습 seed, 모델 적합, 진단 사례나 선택 변동을 포함하지 않는다. 따라서 모집단 수준의 무효과 또는 통계적 유의성 판정으로 사용하지 않는다.

## 불리한 결과와 민감도도 보존

- **후속 반복 간 전달:** 다른 두 반복의 20k 예측으로 남은 한 반복을 고르면 Profile 43.889%, F01 43.741%, 추가 이득 **−0.148%p**다. Greedy20보다 +0.750%p지만 Profile만으로 +0.898%p이므로 이를 F01의 추가 가치로 해석할 수 없다.
- **D 사례를 반씩 나눈 특징:** 기준선은 D50 그대로 두고 교체량만 각 D25에서 계산하면 같은 반복 추가 이득은 −0.167 / −0.185%p다. 교차 반복에서는 +0.019 / +0.278%p로 방향이 달라진다. 이 결과 중 좋은 것을 새 주 결과로 선택하지 않는다. D25마다 주변 성공률도 달라지므로 순수한 측정 오차만의 실험은 아니다.
- **단순화 대조:** 과제별 성능 Profile은 Role보다 선택 성공률은 높았지만 MAE는 나빴다. 예측 오차와 선택 성과는 별도 지표다. 특정 복잡한 기준선이 확정적으로 우월하다는 주장도 하지 않는다.

## 비용과 재현 검증

이번 분석의 신규 환경 step·지속되는 learner update는 모두 **0**이다. 주 분석 wall time은 **1.090초**였다. 각 실행에 Python·패키지 버전, 명령, 입력 SHA-256, 실제 소스 사본과 검사 결과를 남겼다.

가상으로 온라인에서 이 선택을 하려면 같은 반복의 다섯 20k probe에 100k 학습, 선택한 분기의 나머지 20k까지 **총 120k 학습**이 필요하다. 부모 D 평가 평균 62,710.89 step과 다섯 probe D 평가 평균 309,081.94 step도 필요하다. 이미 부모 진단을 갖고 있다면 그 부분은 재사용할 수 있다. Greedy20은 부모 평가가 필요하지 않아 비용에서 제외했다. 교차 반복 방식은 200k probe + 별도 40k 분기로 **240k 학습**, probe D 평가 618,163.89 step이다. 개발 모델 적합용 과거 실험 및 최종 연구용 O 채점 비용은 이 배포 시점 회계 밖의 별도 비용이다. 40k 동일 총예산에서 이겼다는 결과가 아니다.

독립 검산은 원본 episode부터 특징을 다시 만들고, 다른 풀이인 augmented least squares로 모든 예측과 선택·집계를 재계산했다. D/O hash, 성공 사례 pairing, 분모 0 처리, 같은 주변 성공률에서 다른 교체가 가능한지, 조건부 구간까지 확인한다. 검사 통과 수 자체는 과학적 효과의 증거가 아니다.

첫 계산에서 Greedy20에 불필요한 부모 평가 비용을 포함한 것을 정정해 **새 출력 폴더**에서 재실행했다. 과학적 수치에는 변화가 없다. 이전 계산·이전 검산을 보존했다. 기술적으로 실패한 분석 실행은 없었으며, 초기 파일 탐색에서 없었던 경로는 프로토콜에 기록했다.

## 판정과 다음 조건

사전 선별 기준인 평균 추가 이득 1%p 이상·원래 seed 둘 이상 양수·큰 구성별 손실 없음 중 앞의 두 조건을 만족하지 않았다. **이번 초과 교체 요약은 핵심 요인으로 승격하지 않는다.** 과제별 초기 성능은 계속 필수 기준이며, 기존 능력의 보존 자체도 연구 목표에 관련된다.

다시 검증한다면 평균 성공률이 중간 범위인 상태에서 실제 짧은 probe의 사례 교체를 측정하고, 단기 순하락을 통제한 이후의 독립 새 seed 예측·선택 이득을 확인해야 한다. 이번 자료에 맞춰 임계값이나 특징을 계속 늘리는 것은 다음 확인 실험을 대체하지 않는다. 신규 학습이나 추가 rollout은 이 분석에서 실행하지 않았다.
