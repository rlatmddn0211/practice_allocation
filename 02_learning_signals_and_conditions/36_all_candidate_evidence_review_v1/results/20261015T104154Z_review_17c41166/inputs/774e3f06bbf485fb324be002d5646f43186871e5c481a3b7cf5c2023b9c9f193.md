# F06 가소성 후보 — 기존 자료 검증 결과

2026-10-14 KST. **이번 지표를 핵심 배분 요인으로 채택할 근거는 부족하다.** 다른 자료에서의 추가 loss 감소를 넣은 주 비교의 최종 선택 이득은 +0.074%p였고, 36번 중 한 번의 선택 변경에서 발생했다. 휴면 비율·표현 유효 rank의 별도 비교는 +0.102%p였다. 측정과 계산 검산은 완료했지만, 새 seed의 독립 확인과 진단 비용을 포함한 실제 배분 개선은 미검증이다.

**질문과 사전 기준**

현재 성공률, 단기 성공률 변화, critic 진단과 첫 업데이트 반응을 알고도, 신경망이 계속 적응하는 정도를 측정하면 남은 학습의 이득을 더 잘 예측할 수 있는지 물었다. 기존 [8개 후보 설계](../23_candidate_factor_screening_design_v1/research_design_ko.md)의 F06을 [이번 프로토콜](protocol.json)로 구체화했다. 전체 측정 전에 지표·비교·분리·선별 기준을 고정했고 결과에 맞춰 변경하지 않았다. 이미 관찰한 E1·E3 자료를 사용하므로 사전 고정은 새로운 확인 표본을 의미하지 않는다.

주 선별 기준은 기준 모형보다 추가 선택 이득 평균 +1%p 이상, 원래 seed 세 개 중 둘 이상 양수, 어느 구성·시점 집단도 −2%p 미만이 아닐 것이었다. 이 기준은 실무적인 후보 선별선이며 통계적 유의성 검정은 아니다. 별도 정적 지표와 민감도 비교로 주 결과를 대체하지 않았다.

DO/DC는 DrawerOpen/Close, WO/WC는 WindowOpen/Close, PU는 Push, BP는 ButtonPress, PP는 PickPlace다. D/O는 기존 F07의 초기 상태 hash 기반 분리다. 모든 구성·시점에서 같은 원래 seed를 함께 제외하여 예측기를 평가했다. 원래 seed를 제외하는 절차를 지켜도 전체 연구 과정에서 이미 본 역사 자료라는 한계는 남는다.

replay는 모델당 과제별 1,024개씩 두 panel M/A를 사용했다. 시간층을 맞추고 episode는 겹치지 않게 했다. panel 항목 합은 1,572,864개이며, 서로 다른 checkpoint 사이에는 중복 경험이 있으므로 이 수를 전체 고유 경험 수로 해석하지 않는다. A도 과거 replay이므로 새로운 환경 표본은 아니다.

**무엇을 측정했나**

정적 지표는 actor와 두 critic의 마지막 은닉층 ReLU 출력을 사용했다. 뉴런의 평균 절대 활성값을 층 평균으로 나눈 값이 0.01 이하인 비율을 휴면 비율로 정의했다. 임계값 0과 0.1은 사전 민감도 비교로 남겼다. 표현 유효 rank는 중심을 빼지 않은 활성 행렬의 제곱 특잇값 분포에 대한 entropy의 지수값을 층 폭으로 나눴다. 과제는 균등 평균, actor와 두 critic 평균은 각각 절반 가중했다.

이 값은 **해당 과제의 해당 replay panel에서의 활성 요약**이다. 휴면 비율이 높다고 모든 과제에서 해당 뉴런이 영구적으로 죽었다고 말할 수 없다. 중심을 빼지 않은 rank는 공통 활성 성분에도 영향을 받으며, 그 자체로 학습 능력 상실을 입증하지 않는다. 입력 자료의 다양성과 혼동하지 않도록 과제 one-hot을 제외한 원시 상태의 spread와 중심화 rank도 통제했다. 이는 F03의 성공 경험·목표 접근성 검증을 대신하지 않는다.

동적 지표는 원본 모듈과 정확한 Adam 상태를 복제한 뒤 actor·critic 각각 20회 업데이트하여 얻었다. actor는 고정 critic·alpha와 고정 행동 잡음에서 SAC 목적을 줄였고, critic은 원래 actor·target critic으로 만든 고정 soft target에 맞췄다. target network·alpha를 함께 학습하는 실제 SAC 연속 학습은 아니다. 이 진단은 신경망·optimizer·현재 목적의 결합된 적응성을 측정하며 순수한 가소성 원인으로 분리할 수 없다.

매회 256개, 과제별 64개를 사용했다. 첫 16회는 panel을 한 차례 덮고 이후 네 회는 첫 네 batch를 다시 사용했다. 0·1·20회 시점에 학습 panel과 다른 episode panel의 전체 loss를 모두 계산했다. 원래 모델에서 새로 복제하여 M→A와 A→M을 각각 측정했다. 변화량은 0회 시점의 사례별 loss RMS로 나눴다. 따라서 actor의 음수 평균 loss에도 분모가 정의되며, 여기의 정규화 loss 감소율은 성공률 %p와 다르다.

| 비교 | 기준 모형 | 추가 입력 |
| --- | --- | --- |
| 주 비교 `StepBase_F06` | 초기·20k 성능 profile + F05 critic 지표·scale + 원시 상태 범위 + 다른 panel의 0→1회 loss 변화 | actor·critic의 다른 panel 1→20회 loss 변화 두 개 |
| 정적 비교 `CoverageBase_static` | 위 기준에서 0→1회 변화 제외 | 휴면 비율·유효 rank 두 개 |
| 총 변화 비교 `CoverageBase_total20` | `CoverageBase` | 다른 panel의 0→20회 변화 두 개 |
| 반대 panel 비교 | 각 비교에 맞는 기준 | A에서 복제 학습하고 M에서 측정한 지표 |

선형 ridge의 penalty는 가중 평균 오차 기준 1로 고정했다. 입력 표준화도 학습 fold에서만 했다. task·suite·seed ID와 미래 40k 값은 예측 입력에 넣지 않았다. A/B/C 가중은 각각 1/3, A 내부 200k/400k는 절반씩이다. 작은 고정 예측기에서의 증분 검증이며, 다른 표현·비선형 모형까지 배제하는 검증은 아니다.

**loss 적응성에서 관찰한 점**

다음은 180개 20k 분기의 단순 평균이다. 앞의 선택 비교와 달리 A/B/C 균형 가중을 적용하지 않은 기술 통계다. 정규화 loss 감소는 `(처음 loss−마지막 loss)/처음 RMS`이며, 양수면 목적값이 감소했다.

| 진단 | actor | critic |
| --- | ---: | ---: |
| 학습 panel 0→20회 정규화 loss 감소 평균 | +0.000667 | +0.013850 |
| 다른 panel 0→20회 정규화 loss 감소 평균 | +0.000223 | **−0.019769** |
| 다른 panel의 loss가 감소한 분기 | 163/180 | 59/180 |
| 학습 panel 개선·다른 panel 악화 | 17/180 | **85/180** |
| M→A와 A→M 1→20회 반응의 Spearman 상관 | 0.723 | 0.320 |
| 두 방향 반응의 부호 일치율 | 86.7% | 65.0% |

이 진단 조건에서는 critic의 같은 자료 적합이 다른 episode 자료에 그대로 이어지지 않았다. 따라서 같은 replay batch의 loss 감소만으로 추가 연습 가치가 높다고 판단하면 잘못 읽을 가능성이 있다. 다만 고정 target에 대한 짧은 복제 fitting의 관찰이며, 실제 20k SAC의 망각 원인이나 성능 하락을 입증하지 않는다. 이 신호를 보정하면 배분이 좋아진다는 결론도 이번에는 얻지 못했다.

| 20k 모델의 M panel | 휴면 비율 평균 | 정규화 유효 rank 평균 |
| --- | ---: | ---: |
| actor | 47.23% | 0.03343 |
| critic 0 | 45.45% | 0.005245 |
| critic 1 | 45.33% | 0.005210 |

모든 층이 완전히 0인 사례는 없었다. 합성 정적 지표의 M/A 순위 상관은 휴면 0.815, rank 0.707이었다. 관측된 활성 구조가 있다는 사실과 그 구조가 배분을 개선한다는 사실은 구분한다.

**불확실성과 판정 범위**

O 사례만 5,000회 공동 재표집한 조건부 95% 구간은 주 동적 지표 [ +0.019, +0.148 ]%p, 정적 지표 [ −0.009, +0.222 ]%p였다. 주 동적 지표의 구간이 양수여도 **고정된 한 선택 변경에서 평가 사례가 바뀌는 불확실성만** 반영한다. 원래 seed·학습·모형 학습·진단 선택을 다시 수행하지 않았으며, 세 seed 모집단의 일반 효과에 대한 신뢰구간이 아니다. 다른 후속 반복 구간도 같은 한계를 갖는다.

선별 기준에서 주 평균은 +1%p보다 작고 양수 원래 seed는 한 개다. 따라서 **이번 두 동적 요약과 정적 요약은 채택 보류**다. F06 전체 가설이 틀렸다고 결론내리지는 않는다. task별 차이를 압축한 두 특징, 고정 ridge, 기존 replay, 유사한 네 과제 구성, 세 원래 seed만 다뤘다. reset·정규화·optimizer 변경의 인과 기전 실험은 하지 않았다.

wall 합은 실행별 합계이며 병렬 실행과 작성·자료 확인 시간이 있으므로 사용자가 기다린 경과시간과 같지 않다. 전달 감사 비용은 해당 감사 실행의 summary에 별도로 기록한다. 새 환경 step·평가 episode·원본의 지속 학습 update는 모두 0이었다. 위 복제 update는 실제 계산 비용으로 별도 집계했고 결과 정책을 원본에 저장하지 않았다.

본 측정 CUDA event 구간 합은 199.60초, smoke까지 기록된 구간 합은 203.79초다. CPU 작업과 launch 간격이 포함될 수 있어 GPU kernel busy 시간이나 평균 사용률이 아니다. 검산 실행의 CUDA event 시간은 미계측이므로 전체 GPU 시간이라고 부르지 않는다. F05 통제값의 과거 측정 비용도 이번 새 실행 합에 다시 넣지 않았다.

실제 온라인 모사를 하려면 같은 반복 비교는 5×20k probe와 선택한 분기의 잔여 20k, 총 **120k 학습 step**이 필요하다. 다른 반복 비교는 2×5×20k probe와 독립 40k, 총 **240k**다. 예측 규칙의 D 평가 환경 step은 조건 가중 평균으로 부모 약 62,711, probe 약 309,082/618,164가 추가된다. 배포에서 critic/F06 특징을 측정하는 계산, 예측기 개발과 최종 평가 비용도 별도 필요하다. **40k 동일 총예산에서의 개선을 검증한 결과가 아니다.**

**검증과 재현 자료**

원본 checkpoint·replay의 hash와 학습 상태 fingerprint를 전후 대조했다. 192개 모델의 저장된 뉴런 평균·스펙트럼·loss에서 모든 특징을 재구성했다. 결과를 보지 않고 정한 각 구성·시점의 최초 부모·집중 분기, 총 여덟 모델에서는 직접 SVD와 독립 목적식·gradient 계산으로 0/1/20회 loss를 재현했다. 최대 평균 loss 차이는 모두 0.0이었다. zero learning rate 대조에서도 파라미터와 loss가 유지됐다. 별도 예측 검산은 원래 평가 행부터 특징·fold·augmented least squares·선택·비용·구간을 재계산했다.

전체 측정 독립 검사 **178,881개**, 예측·선택 독립 검사 **42,706개**가 통과했다. 검사 수는 효과의 독립 표본 수가 아니다. 첫 smoke의 `profile.py` 이름 충돌은 [실패 기록](technical_failures_ko.md)에 보존했고 이름을 수정한 새 실행을 사용했다. 최종 측정·분석 이후 과학적 프로토콜 변경은 없었다.
