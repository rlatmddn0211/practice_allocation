# 후보 요인 결과 기록 양식

사용 시 새 번호의 독립 버전에 복사한다. 완료한 과거 결과와 실행 디렉터리는 보존한다.
미측정 항목은 ‘미측정’, 확보하지 못한 정보는 ‘미기록’으로 표시하고 추정값으로 채우지 않는다.

| 필드 | 기록할 내용 |
| --- | --- |
| 기록 식별 | 날짜·시간대, F01–F08 ID, 버전, 이전 기록 링크 |
| 질문·가설 | 어떤 조건에서 무엇을 예측하거나 개선할 것으로 기대했는지 |
| 실행 상태 | 설계 / 측정 / 탐색 분석 / 독립 확인 / 비용 포함 실제 배분 비교 중 실제 수행 범위 |
| 사전 기준 | 결과를 보기 전 정한 비교·유지·보류·탈락 기준과 문서 링크; 사후 변경 여부 |
| 실험 설정 | 환경·과제 구성·보상·알고리즘·checkpoint·배분·학습 길이·평가 규약 |
| 표본과 의존성 | 원래 seed·후속 seed·부모 정책·분기·평가 사례 수; 독립 단위와 중복 관계 |
| 정보 사용 시점 | 실제 선택 시점에 얻을 수 있는 입력; 미래 정보 사용 여부; 진단으로 바뀐 정책 상태 |
| 자료 분리 | 개발·선택·채점 분리; 이전에 본 자료인지; 새 독립 확인인지 |
| 비교 기준 | 초기 성능·Uniform·실패율·개발 고정 배분·더 단순한 규칙 등 해당 비교 |
| 정량 결과 | 효과 크기와 단위, 구성·seed별 값, 불확실성 계산과 적용 범위 |
| 불리하거나 불명확한 결과 | 차이 없음, 악화, 조건 간 불일치, 기술 실패, 미실행 대조와 이유 |
| 실제 비용 | 신규 학습·평가 환경 step, update 수, wall/CPU/GPU 시간, 실패·폐기·복제 비용; 미측정 시간은 명시 |
| 모의 비용 | 이미 생성된 자료의 재분석 비용과 실제 적용 시 필요한 비용을 분리 |
| 재현 자료 | 설정·의존성 버전·실행 소스 사본/hash·입력 hash·원자료·분석 표·실행 경로 |
| 기술 검증 | 무결성·계산 검사, 실패 및 복구, 보존된 실패 실행; 효과 증거와 구분 |
| 과학적 판정 | 미검증 / 탐색 지지 / 독립 확인 / 비용 포함 효과 확인 / 근거 부족으로 보류 / 명시한 조건에서 채택하지 않음 |
| 판정의 근거·한계 | 무엇을 확인했고 무엇은 확인하지 못했는지; 일반화 가능한 범위 |
| 다음 판단 조건 | 어떤 추가 결과가 유지·승격·보류·탈락을 바꿀지; 제안과 실행 승인을 구분 |
| 이력 변경 | 이전 판정에서 바뀐 내용·근거·정정 이유; 원래 기록 링크 보존 |

분석이 완료되어도 효과는 미검증일 수 있다. 기술 검사의 개수, 재표집 횟수,
같은 부모에서 만든 분기 수를 독립 연구 근거의 수로 바꾸지 않는다.
요인의 예측력과 그 요인으로 실제 배분했을 때의 비용 포함 성능을 각각 판정한다.
