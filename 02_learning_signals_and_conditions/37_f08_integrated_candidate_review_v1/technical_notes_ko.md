# 검토 범위·수정 이력

2026-10-19. v37은 완료된 F08 결과를 해석하기 위한 읽기 전용 재계산 버전이다. 원래 F08의 학습 스케줄·사전 대조·평가 bank·checkpoint를 수정하지 않았다. ①–⑦의 v36 완료 검토를 재사용했다.

## 실제로 새로 확인한 것

- F08 동결 소스가 campaign 계획의 SHA-256과 일치함.
- 75개 O 파일의 hash, 30,000개 성공 기록, 조건 간 같은 physical case, 72분기 및 부모 점수.
- 144학습 구간의 완료 예산, 5,760개 500-step episode, 총 과제 배분과 순서 조건별 4k block quota, 20k 이후 같은 분기의 checkpoint 연결.
- 모든 21개 사전 대조·paired-case bootstrap 수치의 재계산, 과제별 산술 기여, 사후 leave-one-continuation-out 민감도.
- 별도 코드가 raw 성공 수와 유리수 연산으로 72분기 및 21개 대조·조건 평균·과제 기여를 다시 계산함.
- 225개 F08 worker 비용 영수증: bank 3, 학습 144, 평가 78. 추가 분석·검산 작업 비용은 별도.

원래 144개 full checkpoint 파일의 전면 hash 검산, 구현 smoke의 exact-resume 검증, 전체 simulator 재실행은 v32의 기존 검증 근거를 재사용했다. 새 학습·평가는 없다. F01–F07 전체 모형 적합·gradient·bootstrap도 재실행하지 않았다. 계산 검사 수와 원시 행 수는 과학적 독립 표본 수가 아니다.

## 보존한 오류·수정

1. 초기 탐색에서 `src/practice_allocation/schedules.py`로 잘못 읽어 경로 오류가 났다. 실제 경로 `practice_allocation/schedules.py`를 읽어 확인했다. 파일 변경 없음.
2. 초기 임시 집계에서 CSV BOM을 무시해 `KeyError: suite`가 났다. `utf-8-sig` 읽기로 재실행했다. 이 임시 표는 전달 수치로 사용하지 않았고, 정식 분석은 해당 인코딩을 명시했다.
3. 정식 분석 `20261019T024708Z_review_cef06973`와 독립 검산 `20261019T024727Z_verify_8ec46ef7`은 첫 실행에서 완료했고 failed check 0이다.
4. 첫 그림 `20261019T024727Z_figure_dd9896b7`은 수치가 맞았으나 하단 설명문과 축 라벨이 겹쳤다. 출력은 보존하고 `plot.py`의 하단 여백·설명 위치를 수정했다. 최종 그림은 새 폴더 `20261019T024807Z_figure_e8001806`에 생성했다. 데이터·분석 코드는 바꾸지 않았다.

분석 폴더의 `sources/plot.py`는 그 분석 시점에 존재했던 첫 그림 소스이고, 최종 그림의 실제 실행 소스는 최종 figure 폴더의 `plot.py`와 `summary.json`의 source SHA다. 서로 다른 시점의 소스 snapshot을 덮어쓰지 않았다.

## 전달 점검

고정 Markdown/CSV와 독립 연구용 PNG/SVG를 전달한다. 최종 PNG의 모든 6개 panel·72개 관측점·초기 정책 기준·공통 0–100% 축·범례·주의 문구를 시각 확인한다. SVG는 같은 렌더 데이터로 내보냈으며 별도 브라우저 렌더 검사는 하지 않았다. 범례와 마커를 함께 사용하고, 관측 반복을 신뢰구간처럼 표시하지 않았다. C의 작은 차이는 공통 축에서 작게 보이므로 정확한 원값을 CSV와 본문 표에 함께 남긴다.

README의 최신 상태를 ⑧ 완료로 갱신하되, 36번 등 과거 버전의 작성 당시 “진행 중” 표기는 역사 기록으로 유지한다. 본문은 ⑧의 사전 대조와 새 사후 분해를 구분하고, 다른 후보와 단순 효과 크기 순위를 만들지 않는다. 한계를 명시한 탐색 결과로 공유 가능하며, 독립 원래 seed·인과 메커니즘·비용 포함 온라인 효과는 검증 범위 밖이다.
