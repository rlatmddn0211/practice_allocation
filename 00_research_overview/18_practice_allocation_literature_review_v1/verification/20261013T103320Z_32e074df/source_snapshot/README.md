# 추가 연습 배분 연구의 선행연구 비교

작성 기준일: 2026-10-13. 기존 실험을 변경하지 않는 문헌 검토 버전이다.

- [정밀 비교 보고서](literature_review_ko.md): 주제의 중복 범위, 주요 논문별 비교, 가능한 기여와 검증 조건.
- `sources.json`: 검토한 원문, 버전, 확인 위치와 해석의 한계.
- `search_log.json`: 검색 범위, 주요 질의, 접근 실패와 대체 원문.
- `comparison.csv`: 핵심 논문의 비교표. `sources.json`에서 생성한다.
- `verify_review.py`: 링크·문헌 메타데이터·파일 무결성을 검사하고 새 `verification/` 하위 폴더에 소스 사본과 해시를 남긴다. 문헌 해석의 타당성을 자동으로 증명하는 검사는 아니다.

핵심 판단: 현재 주제 문장 자체의 차별화는 낮다. 예산을 고려한 로봇 연습, 전이 예측, 온라인 혼합비 추정, 진단 비용을 고려하는 실험 선택 모두 직접적인 선행연구가 있다. 공유 정책의 로봇 강화학습에서 유한 예산의 성능 변화를 예측하고 진단비까지 회수하는 방법은 검증할 후보이나, 이번 검토만으로 미개척 문제라고 단정하지 않는다.

이 버전은 신규 학습·환경 평가를 실행하지 않는다. E0–E3의 승인된 프로토콜, 기존 결과, 실행 큐는 수정하지 않는다. 보고서의 후속 실험 제안은 실행 승인이 아니다. 전달 후 이 폴더도 고정 버전으로 취급한다.
